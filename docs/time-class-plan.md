## 1. 배경

운영자가 가져온 Claude 아티팩트 '시각과 시간 교실 시계'(탭 5개)를 시뮬레이션 앱으로 옮긴다.
운영자 결정(2026-11-11):

- **새 앱으로, 탭 5개 모두** 넣는다. 기존 `clock`(시계 보기)은 학생 미션용으로 그대로 두고 서로 연결한다.
- 원본에 없던 것 세 가지를 더한다: **학생 미션**, **일과표 다듬기**, **시계 보기에도 도움 표시 반영**(clock-plan.md 10장).
- 공유 링크·QR은 이번에 하지 않는다.
- 이름 '시각과 시간', 주소 `/apps/time-class/`.
- 인트로 화면 아래에 원본 아티팩트를 참고했다는 안내와 링크를 작게 둔다(https://claude.ai/artifact/YELk82vF74HVHddV7znEZJ).

## 3. 화면

```
[인트로] → 본 화면(왼쪽 무대 + 오른쪽 조작판) → [미션 결과]
모드: 시각 읽기 · 걸린 시간 · 하루 · 일과 · 달력 · 미션
```

원본은 위쪽 탭 + 탭마다 다른 배치였다. 우리 시뮬레이션 관행(무대 왼쪽, 조작판 오른쪽, 조작판 안 모드 탭)에 맞춘다. 좁은 화면은 위(무대)·아래(조작판).

| 모드 | 무대 | 조작판 |
|---|---|---|
| 시각 읽기 | 큰 바늘 시계 + 전자시계 + 읽는 글 | 바늘 옮기기(±1시간·5분·1분, 오전↔오후, 지금 시각, 시계 흘러가기, 끌기 단위), 시계 모양, 도움 표시 9가지, 문제 내기(교사용) |
| 걸린 시간 | 시작·끝 시계 2개 + 시간 띠(한 칸 10분) | 걸린 시간(가리기), 시작부터 돌려보기, 시계마다 ± 버튼 |
| 하루 | 12시간 시계 + 24시간 시계 + 하루 띠 | 지금 시각 글, 하루 돌려보기(빠르기 3단계), 바늘 바퀴 수 |
| 일과 | 원 그림 + 막대 그림 | 활동 목록(이름·색·시작·끝), 더하기, 예시, 모두 지우기, 인쇄 |
| 달력 | 달력 | 날짜 고르기/두 날 사이 재기, 하루·1주일 이동, 표시 글, 날짜 가리기, 달마다 날수 |
| 미션 | 미션에 맞는 무대 | 문제·입력·확인 |

공통: 12시간제/24시간제 전환, 전체 화면(조작판 머리).

## 4. 원본에서 고친 점 (기본 적용)

- 화면 규약 v2: `.sk-btn`, lucide 아이콘, 토스트 위쪽, 밝은 화면 고정, `.sk-screen` 인트로·결과.
- 저장은 `SimKit.store('time-class:v1')` 하나로 모으고 불러올 때 검사(원본은 키 6개, 무검사).
- 바늘·하루 띠를 키보드로 조작(←/→ 한 단계, ↑/↓ 1시간), `role="slider"` + 읽기 글.
- 움직임 줄이기 설정이면 버튼으로 옮길 때 바늘이 바로 이동한다. 돌려보기(시계 흘러가기·하루 돌려보기)는 움직임이 내용이라 그대로 둔다.
- 달력 표시 글·활동 이름은 `textContent`로만 그린다.
- 글투: 엠대시 없음, 초등 눈높이.

## 5. 더한 것

### 5-1. 학생 미션 (6개, 미션마다 3문제)

| # | 미션 | 방식 |
|---|---|---|
| m1 | 걸린 시간 구하기 | 시작·끝 시계 → 시간·분 고르기 |
| m2 | 끝난 시각 맞추기 | "2시 40분에 시작해 50분 동안" → 끝 시계 바늘을 돌려 맞춤(60분을 넘기는 문제 포함) |
| m3 | 오전과 오후 | 하루 띠에 표시된 시각·생활 장면 → 오전/오후 |
| m4 | 24시간으로 말하기 | "오후 3시는 몇 시?" → 보기 4개 |
| m5 | 달력에서 날짜 찾기 | "5월 5일에서 1주일 뒤" → 달력에서 날짜 누르기 |
| m6 | 요일과 날수 | "며칠 뒤는 무슨 요일?", "이 달은 며칠까지?" → 보기 |

- 별: 3문제 중 첫 시도에 맞힌 수. `keepBest`.
- 틀리면 도움말 한 번 뒤 같은 문제 다시, 두 번째도 틀리면 정답을 보여 주고 다음 문제.
- 자동 이동 없음. [다음 문제] / [다음 미션] 버튼.
- 미션 중 [자유 탐험으로] 항상 보임.

### 5-2. 일과표 다듬기

- **겹침 알림**: 두 활동 시간이 겹치면 목록에 경고와 함께 어느 활동끼리인지 알려 준다.
- **끌어서 시간 바꾸기**: 고른 활동의 시작·끝 손잡이를 원·막대에서 끌면 5분 단위로 바뀐다.
- **비어 있는 시간**: 하루 24시간 중 정한 시간 합계와 비어 있는 시간을 보여 준다.
- **인쇄**: 원·막대 그림과 활동 표를 A4 한 장으로.

## 7. 기술 메모

- 시각은 '하루를 넘어 이어지는 분'(정수)으로 들고 다닌다. 표시할 때 0~1439로 감는다. 바늘 끌기는 직전 각도와의 차이(−180~180)를 더한다(분침 1도 = 1/6분, 시침 1도 = 2분).
- 시계 SVG `viewBox="-250 -250 500 500"`. 색은 시계 보기와 같게: 짧은바늘 주황, 긴바늘 파랑.
- 달력 날짜 계산은 `Date.UTC` 날수로(서머타임 영향 없음).
- 저장 모양: `{ mode24, tab, read:{opts,disp}, routine:[{name,s,e,c}], rtView, marks:{'YYYY-MM-DD':글}, progress:{m1..m6} }`.

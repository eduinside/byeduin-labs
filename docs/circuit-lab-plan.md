### 교과 근거 (2022 개정, 6학년 「전기의 이용」)
- 전지·전선·전구로 회로를 구성하고 **전구에 불이 켜지는 조건** 찾기
- 전구의 **직렬연결과 병렬연결**에서 밝기 비교
- 전지의 **직렬연결**로 밝기 세지는 것 관찰
- 스위치로 회로를 여닫음
- (연계) 전기 안전 — 합선(단락) 위험을 정성적으로 인지

### 학습 목표
1. 전지의 양극-전구-음극이 **끊김 없이 이어져야(닫힌 회로)** 불이 켜짐을 발견한다.
2. 전구 직렬은 하나가 빠지면 모두 꺼지고, 병렬은 하나가 빠져도 나머지가 켜짐을 안다.
3. 전구를 직렬로 늘리면 어두워지고, 전지를 직렬로 늘리면 밝아짐을 비교한다.
4. 스위치로 회로를 여닫아 흐름을 제어한다.

### 오개념 교정 포인트
- **"전지에 전구만 대면 켜진다(한 선만)"** → 닫힌 회로(두 극 모두 연결) 필요를 배선 실패로 즉시 체감.
- **"직렬이 병렬보다 항상 밝다"** → 전구 직렬은 오히려 어두워짐(나눠 가짐)을 밝기 애니메이션으로 반증.
- **"전지 양극-음극을 전선으로 바로 이으면 된다"** → 합선(단락) 경고 연출로 위험 인지.

## 2. 화면 흐름

```
[인트로] → [자유 탐험: 배선 공작소] → [미션 단계별] → [결과 정리]
```

### 2-1. 인트로
- 미션 카드: "전지, 전구, 전선으로 불을 켜 볼까요? 어떻게 이어야 불이 들어올까요?" + `시작하기`.

### 2-2. 자유 탐험 — 배선 공작소 (핵심)
- **부품 팔레트**: 전지🔋 · 전구💡 · 스위치🎚️ · 전선. 드래그해 격자 캔버스에 배치.
- **배선**: 부품의 단자(노드)를 드래그로 이어 전선 생성. 격자 스냅으로 정렬·판정 단순화.
- **실시간 판정**: 배선이 바뀔 때마다 회로를 재평가 →
  - 닫힌 회로 + 전구 포함 → 전구 **점등**(밝기 정성값에 따라 광량 애니메이션)
  - 스위치 열림/전선 끊김 → 소등
  - 전지 양극↔음극이 전구 없이 직결 → **합선 경고**(빨강 점멸 + "전지가 뜨거워져요! 위험해요")
- **조작 피드백**: 전구 밝기를 3~4단계 상대값으로 표시(밝음/보통/어두움). 스위치 탭으로 개폐.
- 자유롭게 여러 전구·전지를 붙여 보며 직렬/병렬 실험.

### 2-3. 미션 (단계별)
| 단계 | 유형 | 예 |
|------|------|----|
| ① 불 켜기 | 전지 1·전구 1로 닫힌 회로 완성 | "불을 켜 보세요" |
| ② 스위치 | 스위치를 넣어 껐다 켰다 되게 | |
| ③ 직렬 전구 | 전구 2개 직렬 → "하나를 빼면?" 예측→확인(둘 다 꺼짐) | |
| ④ 병렬 전구 | 전구 2개 병렬 → "하나를 빼면?" 예측→확인(나머지 켜짐) | |
| ⑤ 밝기 비교 | 전구 직렬(어두움) vs 전지 직렬(밝음) 만들어 비교 | |
| ⑥ 안전 | 합선 회로를 보여주고 "무엇이 위험할까요?" 인지 | |
- ③④⑤는 **예측→확인 원칙**: 전구 제거/추가 전 결과를 버튼으로 예측 후 실행해 확인.
- 별점: 최소 부품/최소 배선 달성 기준 + 첫 시도 정답.

### 2-4. 결과 / 배움 정리
- 정리 카드: "전지의 두 극이 전구를 지나 **끊김 없이 이어져야** 불이 켜져요. 전구를 직렬로 늘리면 어두워지고, 전지를 직렬로 늘리면 밝아져요."
- `다시` / `공작소로` / 공유(내가 만든 회로).

## 3. 기술 설계 — 회로 판정 (이 앱의 핵심 난이도)

### 3-1. 회로 모델
```
회로 = 그래프
  nodes = 부품 단자(전지 +/-, 전구 양단, 스위치 양단)
  edges = 전선(노드-노드) + 부품 내부 연결(전구 양단, 닫힌 스위치)
components = [ { type:'battery'|'bulb'|'switch', terminals:[nodeIds], state } ]
```

> **재검토 보완(2026-07-03)**: 초판의 "서로소 경로 집합으로 직렬/병렬 근사"는 직렬-병렬 혼합 회로(예: 병렬 2개가 다시 다른 전구와 직렬)에서 깨진다. 아래처럼 **전기 노드 병합(union-find) + 표준형 분류**로 바꾸고, 밝기 주장은 교과가 다루는 표준형에만 한정한다.

#### 3-2-1. 전처리 — 전기 노드 병합
- 전선·닫힌 스위치로 직접 이어진 단자들을 union-find로 하나의 **전기 노드**로 병합. 열린 스위치는 병합하지 않음(끊김).
- 결과: 회로가 "전기 노드"와 "부품(노드쌍을 잇는 간선)"으로 이루어진 축약 그래프가 됨.

#### 3-2-2. 점등 판정 (모든 회로에 적용)
1. **닫힌 회로**: 전지 +노드에서 전구를 지나 -노드로 돌아오는 경로(전지 간선 포함)가 존재하면 그 전구는 켜짐. 경로 탐색은 축약 그래프에서 단순 경로 열거(부품 수 상한이라 비용 무시 가능).
2. **전구 우회(합선된 전구)**: 어떤 전구의 두 단자가 **같은 전기 노드**에 속하면(전선이 전구를 가로질러 이음) 그 전구는 **소등**(전류가 우회). — 교과의 "합선" 개념을 정확히 표현.
3. **전지 단락**: 전지 +노드와 -노드가 전구를 하나도 거치지 않고 연결되면 **합선 경고** 플래그.

#### 3-2-3. 밝기 — **표준형에만 주장** (핵심 보완)
회로를 4가지 표준형으로 분류하고, 그 경우에만 상대 밝기를 표시한다. 그 외(혼합·비정형)는 "**켜짐**"만 표시하고 밝기 등급은 매기지 않는다(오개념 방지 — 초등 교과는 혼합회로 밝기를 다루지 않음).

| 표준형 | 인식 조건 | 밝기(기준 대비) |
|--------|-----------|------------------|
| 기본 | 전지 1 · 전구 1 닫힌 회로 | **기준(2/3단계)** — 앵커 |
| 전구 직렬 | 한 경로에 전구 N개, 병렬 가지 없음 | 기준 ÷ N (어두워짐) |
| 전구 병렬 | 전지 두 노드 사이 서로 독립한 전구 가지 N개 | 각 전구 = 기준 (유지) |
| 전지 직렬 | 한 경로에 전지 M개 직렬, 전구 1 | 기준 × M (밝아짐, 최대 3단계로 클램프) |

- **밝기 앵커**: 전지1·전구1 = 3단계 중 2단계. 전구 직렬 시 1단계, 전지 직렬 시 3단계로 떨어지고 오르게 하여 "직렬 전구=어두움 / 직렬 전지=밝음"의 대비가 등급으로 드러나게 함.
- 최종 밝기는 3단계(어두움/보통/밝음)로 양자화. **수치·단위(V·A·Ω) 노출 없음.**

> 초등 스코프(전구 ≤ 4, 전지 ≤ 3)로 좁혀 일반 회로 해석(행렬/키르히호프)을 피하되, **밝기 등급은 교과가 정의한 표준형에만 부여**한다. 표준형 밖 회로는 "불은 켜지지만 밝기 비교는 하지 않음"으로 처리해 근거 없는 밝기 주장을 원천 차단.

### 3-3. 렌더링 · 드래그
- **SVG**: 부품은 인라인 SVG 심볼, 전선은 `<path>`(격자 직교 라우팅), 전구 빛은 `<radialGradient>` + 밝기 단계별 알파. 드래그·배선은 포인터 이벤트.
- 전류 흐름 시각화(선택): 점등 시 전선 위 점들이 흐르는 애니메이션(방향 표시 — 단, "전자 이동" 정량 아님).

> **재검토 보완 — "드래그 컴포넌트 재사용"의 실체**: 이 프로젝트는 앱마다 단독 `index.html`이고 `/common/`에는 프레임워크 파일(theme·app-shell·init 등)만 있으며, 기존 앱에 공유 드래그 로직이 없다. 따라서 D(양팔저울)에서 "만들어 재사용"한다는 초판 서술은 그대로는 성립하지 않는다. 두 방식 중 택1로 명확히 한다:
> - **(권장) `/common/drag-connect.js` 신설** — 단자-스냅·간선 드로잉·포인터/터치 정규화를 담은 프레임워크급 헬퍼를 공통 폴더에 추가하고, eco-web·circuit-lab·양팔저울이 `<script src="/common/drag-connect.js">`로 공유. 최초 도입 앱(D)이 이 파일을 만든다.
> - **(대안) 패턴 복사** — 공통화 없이 각 앱이 동일 스니펫을 복제. 유지보수 부담이 있으므로 3개 앱이 예정된 지금은 (권장)안이 낫다.
> 어느 쪽이든 **접근성 대체 조작 필수**: 드래그 불가 사용자를 위해 "단자 탭 → 대상 단자 탭"의 2탭 연결 모드와 키보드 포커스 이동을 병행 제공한다.

### 3-4. 상태 · 저장 · 공유

## 4. 디자인

- 공통 3종 + 표준 스크립트, `immersive` 셸.
- 팔레트: `--cc-wire`(전선), `--cc-on`(점등 노랑), `--cc-off`(소등), `--cc-danger`(합선 경고 빨강), `--cc-node`(단자). 색+아이콘 병용.
- 부품/단자 터치 타깃 ≥ 44px, 격자 스냅으로 배선 난이도 완화. 잘못된 연결은 흔들림 피드백.
- 다크모드에서 전선·점등·경고 대비 확인.

## 5. 스코프 제한 (Non-goals)

- **옴의 법칙·전압/전류/저항 수치 없음**(정성만). 키르히호프·행렬 회로 해석 없음.
- 부품 수 상한(전구 ≤ 4, 전지 ≤ 3, 스위치 ≤ 2) — 규칙 기반 판정이 성립하는 범위로 고정.
- 전자석·발광 다이오드·저항기·콘덴서 등 추가 부품 없음(v1은 전지·전구·스위치·전선). 전자석은 확장 여지(`v` 필드).
- 실제 전기 안전 교육 대체 아님(합선 경고는 개념 인지용).

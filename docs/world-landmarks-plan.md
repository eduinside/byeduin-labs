# world-landmarks — 세계 탐험대 개발문서

> 작성: 2026-07-04 · 작성자: Claude Fable 5 · 상위 기획: [simulation-apps-plan.md](simulation-apps-plan.md) (저학년 통합교과 라인)
> 제약: 순수 정적 SPA(단일 HTML) · localStorage만 사용 · 외부 CDN은 MapLibre(volcano와 동일)만
> 벤치마크: `volcano`(화산 탐험대) — 동일 스택·동일 흐름의 **자매 앱**. "화산 대신 랜드마크, 관찰 카드 대신 나라 문화 카드."

## 1. 개요

| 항목 | 값 |
|------|-----|
| 앱 ID | `world-landmarks` (`/apps/world-landmarks/`) |
| 이름 · 이모지 | 세계 탐험대 · 🌏 |
| 셸 | `immersive` (volcano와 동일, 전체화면 3D 지도) |
| 카테고리 | `edu` / `edu-sim` · 배지 `시뮬레이션` |
| 한 줄 | 3D 위성지도로 세계 랜드마크를 탐험하고 그 나라의 국기·수도·의상·음식·집을 알아보는 세계 문화 여행 |
| 교과 | 1~2학년군 통합교과(바슬즐) 대주제 「세계」 — 2학년 적용 |
| 대상 | 초등 저학년(2학년 중심) · 태블릿/크롬북/스마트폰 |

### 교과 근거
2022 개정 통합교과 8개 대주제(학교·사람들·우리나라·탐험·나·자연·마을·세계) 중 「세계」: 다른 나라의 문화(옷·음식·집·놀이·인사)를 경험하고 문화의 다양성을 존중하는 내용. 성취기준은 1~2학년군 단위 고시.

> ⚠️ 조사 한계: 본 기획 시점에 웹 조사가 불가하여 성취기준 코드·교과서 차시는 미대조. **구현 착수 전 교과서(「세계」 단원) 차시 흐름과 대조**할 것(검수 체크리스트 포함).

### 학습 목표
1. 세계 여러 나라에 관심을 갖고, 나라마다 대표 장소(랜드마크)가 있음을 안다.
2. 국기·수도·음식·옷·집 등 문화 요소가 나라마다 다름을 안다.
3. "다른 것은 틀린 것이 아니다" — 다양성을 존중하는 태도의 씨앗.

## 2. 설계 대원칙 (문화 콘텐츠 안전)

1. **본질화 금지**: "프랑스 사람은 ○○를 입는다" ❌ → "프랑스의 **전통** 옷이에요 / 특별한 날 입기도 해요" ⭕. 모든 의상·음식·집은 "대표적인 모습 **중 하나**"로 프레이밍.
2. **비교 우열 금지**: 나라 간 크기·부유함 비교 없음. 모든 나라 카드는 동일한 구조·동일한 분량.
3. **저작권 0 정책**: 사진 사용 안 함. 의상·음식·집·랜드마크 일러스트는 **이모지 + 자체 제작 인라인 SVG**만. 위성 이미지는 volcano와 동일한 ArcGIS World Imagery 타일(기존 관행).
4. **국기는 인라인 SVG 자체 제작**: Windows 크롬북/PC의 Chrome은 **국기 이모지를 렌더링하지 못함**(문자 쌍으로 표시) → 국기 이모지 의존 금지. 11개국 국기를 단순 기하 SVG로 내장(태극기·일장기·삼색기 계열은 쉬움, 문장(紋章) 있는 국기는 단순화 버전 + "실제 국기는 더 자세해요" 각주).

## 4. 화면 흐름 (volcano 패턴 이식 + 여권 메타포)

1. **인트로** — 미션 카드: "🛫 세계 여행을 떠나요! 랜드마크 11곳을 찾아가 **여권 도장**을 모아 보세요." + 시작.
2. **자유 탐험** — 전체화면 3D 위성지도. 랜드마크 마커 11개(이모지 핀). 마커 탭 → `flyTo` 비행 연출(비행기 이동선 = "여행" 체감) → 도착.
3. **랜드마크 관찰** — volcano의 관찰 단계처럼 3D로 둘러보기(회전·줌 가이드 1줄). "무엇이 보이나요?" 관찰 포인트 1~2개.
4. **나라 카드** — 하단 시트(저학년용 큰 카드):
   - 국기(SVG) · 나라 이름 · 수도 · 인사말("봉주르!")
   - 그림 중심 3칸: 🍞 음식 / 👘 옷 / 🏠 집 — 각각 이모지+SVG 일러스트 1개 + **한 문장**(존중 프레이밍, §2)
   - 🔊 읽어주기 버튼(Web Speech API, 지원 안 되면 버튼 자동 숨김) — 2학년은 읽기 부담 최소화.
5. **미니 퀴즈(도장 조건)** — 글 최소화, **그림 매칭형** 1문항: "이 국기는 어느 나라?"(국기→랜드마크 3지선다) 또는 "이 음식은 어느 나라?" → 정답 시 **여권 도장 쾅!**(스탬프 애니메이션 + 효과음 옵션).
6. **여권 화면** — 모은 도장 그리드. 11개 완성 시 "🎖️ 세계 탐험 챔피언" 수료증 + 배움 정리("나라마다 국기·음식·옷·집이 달라요. 달라서 더 재미있어요!").

## 5. 기술 설계

### 5-1. 지도 스택 (volcano 100% 재사용)
- MapLibre GL 4.7.1(cdnjs) + ArcGIS World Imagery raster + terrarium DEM(3D terrain) + `mapFallback`(라이브러리/WebGL 실패 시 안내). 검증된 코드라 신규 리스크 없음.
- **지도 실패 fallback 강화**: volcano는 실패 시 안내만 하지만, 본 앱은 **지도 없이도 나라 카드+퀴즈만으로 학습 가능한 "카드 모드"**로 자동 전환(저학년 교실의 구형 기기 대비).

### 5-2. 데이터 모델
```
landmarks = [{ id, name, emoji, country:{ nameKo, capital, greeting,
               flagSvgId, food, clothes, house }, camera:{lng,lat,zoom,pitch,bearing},
               observe:[...], quiz:{...} }]   // 정적 상수
```

### 5-3. 저장 · 공유
- `localStorage` 키: `world-landmarks:v1` → `{ stamps:[id...], settings:{tts,sound} }`.
- 공유: `#share=` payload `{ v:1, focus:landmarkId }`(특정 랜드마크로 바로 여행) + 여권 완성 공유. `shareCurrentPage()` 단축링크.

### 5-4. 의존성
- 외부 CDN은 MapLibre + 지도 타일만(volcano와 동일). **서버·DB 없음** — 순수 정적 원칙 그대로 준수.

## 6. 디자인

- 공통 3종(`hero-theme.css`·`app-shell.css`·`theme.js`) + 표준 스크립트, `immersive` 셸.
- 팔레트: 하늘/여권 남색 + 도장 빨강 계열 커스텀 변수.
- 저학년 규격: 터치 타깃 ≥ 48px(4학년 대상 앱보다 상향), 문장당 ≤ 25자, 카드당 문장 ≤ 3개, Jua 등 기존 라운드 폰트.
- 다크모드에서 국기 SVG 흰 배경 국기(일장기 등)에 테두리 필수.

## 7. 스코프 제한 (Non-goals)

- v1은 랜드마크 11곳 고정 — 나라 추가는 후속(`v` 필드) 확장.
- 실사 사진·외부 이미지 없음(저작권 0 정책). 지구본 projection(MapLibre v5 globe)은 후속 검토 — v1은 volcano와 동일한 4.7.1 유지.
- 국경선·영토 표기 없음 — 위성 raster 타일이라 정치적 경계 이슈 자체가 발생하지 않음(의도된 선택).
- 다국어(영어) UI 없음. 인사말 한 마디만 원어 노출.

## 8. 제작·배포 절차

1. 스캐폴드:
   ```bash
   node scripts/scaffold-app.js --id world-landmarks --name "세계 탐험대" --base immersive \
     --category edu --subcategory edu-sim --emoji 🌏 --desc "3D 위성지도로 세계 랜드마크 11곳 탐험, 나라별 국기·문화를 알아보는 여권 수집 여행"
   ```
2. `apps.json` 수동 보강: `badge: "시뮬레이션"`, SEO:
   - `seo.title`: `세계 탐험대 — 3D 지도 세계 랜드마크·나라 문화 여행`
   - `seo.description`: `에펠탑·피라미드 등 세계 랜드마크 11곳을 3D 위성지도로 탐험하고 나라별 국기·수도·음식·옷·집을 알아봐요. 여권 도장을 모으는 초등 저학년 세계 문화 학습 앱.`
   - `seo.keywords`: `세계 랜드마크`, `세계 여러 나라`, `국기`, `세계 문화`, `초등 통합교과`, `3D 지도`
3. 구현 → `npm run dev` → `npm run inject` → `npm run og` → `npm run sitemap` → 커밋.

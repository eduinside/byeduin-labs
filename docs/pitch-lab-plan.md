> 작성: 2026-10-09 · 공용 키트: [sim-kit.md](sim-kit.md) · 화면 틀: [sun-shadow-plan.md](sun-shadow-plan.md)과 같은 immersive + 조작판

### 잡아야 할 오개념
1. **소리를 크게 내면 높아진다** → 세기(떨림의 크기)와 높낮이(떨림의 빠르기)는 따로. 화면에서 세기 막대와 음높이 줄을 나눠 보여 준다.
2. **높은 소리는 떨림이 크다** → 높은 소리는 떨림이 *빠르다*(1초에 더 많이 떨린다). 파형을 같은 시간 폭으로 그려 촘촘함을 비교.
3. **오토튠은 목소리를 바꿔 주는 마법** → 음높이를 재고, 가장 가까운 음의 줄로 옮기는 계산이다. 고치기 전후 곡선을 겹쳐 보여 준다.

## 2. 모드

| 탭 | 무대(왼쪽) | 조작판(오른쪽) |
|---|---|---|
| 관찰 | 시간–음높이 그래프(최근 8초, 음 줄 = 계이름 도레미…, 가운데 도 표시), 떨림 모양(파형), 세기 막대, 큰 계이름·Hz·튜너 바늘 | 소리 고르기: **마이크** / **소리 발생기**(높이 슬라이더 100~1000Hz, 세기 슬라이더, 반음 ±, 음 버튼 도~높은 도). 표시 단위(계이름/음이름) |
| 음 보정 | 녹음 전체의 음높이 곡선: 원래 소리(주황) vs 고친 소리(파랑), 재생 위치 선 | 녹음(최대 8초) 또는 **예시 노래**(음이 어긋난 "학교 종" 합성음), 음계(반음 모두 / 도레미 / 도레솔라미 5음), 보정 세기 0~100%, 보정 빠르기(천천히~즉시=로봇 목소리), 음높이 옮기기 −12~+12 반음, 원래 소리/고친 소리 듣기 |
| 미션 | 미션별 그림(파형 비교·음높이 그래프·보정 곡선) | 미션 5개 |

- 마이크는 사용자가 버튼을 눌렀을 때만 켠다(권한 창). 막히거나 없으면 토스트로 알리고 소리 발생기·예시 노래로 계속할 수 있다. **마이크 없이도 모든 미션을 풀 수 있게** 한다.
- 마이크로 들은 소리는 실시간으로 스피커에 내보내지 않는다(교실 하울링 방지). 음 보정은 "녹음 → 계산 → 듣기" 방식.
- 녹음은 메모리에만 두고 저장·전송하지 않는다.

## 3. 계산 모델

| 항목 | 방법 |
|---|---|
| 음높이 찾기 | YIN(차이 함수 + 누적 평균 정규화 + 포물선 보간), 창 2048 샘플, 범위 70~1100Hz, 문턱 0.15. 세기(RMS)가 너무 작으면 "소리 없음" |
| 계이름 | 12평균율, 라 = 440Hz. 도4 = 261.6Hz를 "가운데 도". 반음 단위 차이를 센트(1반음 = 100센트)로 바늘 표시 |
| 음 보정 목표 | 프레임마다 지금 음높이 f → 음계에서 가장 가까운 음 n. 목표 = f · (n/f)^세기. 보정 빠르기 = 비율의 1차 지연(0ms~200ms). 음높이 옮기기는 비율에 2^(반음/12)를 곱함 |
| 음 바꾸기 | TD-PSOLA: 원래 소리의 주기마다 표지(가장 큰 값으로 맞춤)를 찍고 두 주기 길이 한 창(Hann) 조각을 목표 주기 간격으로 다시 겹쳐 더함. 길이(빠르기)는 그대로. 무성음 구간은 10ms 조각을 그대로 복사. 창 무게 합으로 나눠 세기 유지 |
| 예시 노래 | "학교 종이 땡땡땡" 첫 두 마디(솔솔라라솔솔미 솔솔미미레)를 배음 합성 + 떨림(비브라토)으로 만들고, 일부 음을 ±30~60센트 어긋나게, 음 사이를 미끄러지게 |

## 4. 미션 (5개, 별 = 시도 횟수 0→3, 1→2, 그 외 1)

| # | 제목 | 방식 | 채점 |
|---|---|---|---|
| m1 | 더 높은 소리 | 소리 ㉮(도4)·㉯(도5) 들어 보고 고르기 | 보기. 뒤에 두 파형을 같은 시간 폭으로 비교 |
| m2 | 목소리로 '솔' 내기 | 마이크 또는 소리 발생기로 솔(어느 옥타브든)을 ±40센트 안에서 1초 유지 | 자동(유지 막대가 차면 완료) |
| m3 | 크게 내면 높아질까? | 보기 | 세기만 커짐. 뒤에 같은 높이·다른 세기 파형 |
| m4 | 한 옥타브 위의 도 | 소리 발생기로 도4(262Hz)의 한 옥타브 위 도를 찾아 [확인하기] | ±25센트(523Hz). 진동수가 2배임을 설명 |
| m5 | 오토튠의 원리 | 보기 | "가장 가까운 음 높이로 옮긴다" |

> 2026-10-09: 처음 넣었던 "어긋난 음 고치기"(예시 노래를 보정 세기·속도로 고쳐 평균 오차 ≤ 12센트)는 초등 학생에게 어려워 미션에서 뺐다. 같은 활동은 음 보정 탭에서 자유롭게 해 볼 수 있다.

## 5. 저장·공유

- `SimKit.store('pitch-lab:v1')`: `{ progress, scale, strength, speed, shift, names }`.
- 공유: 설정만(`{ v:1, mode, scale, strength, speed, shift }`). 소리는 공유하지 않는다.

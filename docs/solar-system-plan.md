# solar-system — 태양계 여행 개발문서

> 작성: 2026-07-03 · 작성자: Claude Fable 5 · 상위 기획: [simulation-apps-plan.md](simulation-apps-plan.md) (천체 라인업)
> 제약: 순수 정적 SPA(단일 HTML) · localStorage만 사용 · 외부 의존성 0(폰트 제외)
> 설계 대원칙: **크기와 거리를 동시에 실척으로 못 보여주는 딜레마를 "모드 토글"로 전환** — 교과서도 크기 비교와 거리 비교를 따로 다룸. 이 전환의 충격이 곧 학습.

## 1. 개요

| 항목 | 값 |
|------|-----|
| 앱 ID | `solar-system` (`/apps/solar-system/`) |
| 이름 · 이모지 | 태양계 여행 · 🪐 |
| 셸 | `immersive` (우주 뷰포트를 앱이 소유, 팬/줌 조작) |
| 카테고리 | `edu` / `edu-sim` · 배지 `시뮬레이션` |
| 한 줄 | 여덟 행성을 공전시키고, 크기와 거리를 비교하고, 각 행성을 탐방하는 태양계 종합 시뮬레이션 |
| 교과 | 초등 5~6학년군 「태양계와 별」 |
| 대상 기기 | 태블릿·크롬북·스마트폰 |

### 교과 근거 (2022 개정, 5~6학년군 「태양계와 별」)
- 태양계 구성원 조사(태양, 행성 8개; 위성·소행성 등)
- 행성을 **상대적 크기로 비교**(지구 기준)
- 행성을 **태양으로부터의 상대적 거리로 비교**
- 태양이 지구 에너지의 근원임을 이해
- (연계) 별과 별자리 — v1 스코프에서는 행성 중심, 별자리는 확장 여지

### 학습 목표
1. 태양계 구성원과 여덟 행성의 순서를 안다(수·금·지·화·목·토·천·해).
2. 행성의 크기 차이(목성·토성 거대, 수성·화성 작음)를 상대적으로 비교한다.
3. 태양에서 멀어질수록 간격이 급격히 커짐을 안다.
4. **크기 비교와 거리 비교는 한 그림에 담을 수 없음**을 체감한다(스케일 개념의 씨앗).

### 오개념 교정 포인트
- **"교과서 그림처럼 행성이 옹기종기 붙어 있다"** → 거리 비교 모드에서 실제 비율의 광활함을 스크롤/줌으로 체감.
- **"큰 행성이 태양에서 멀다"** → 크기와 거리는 무관(목성은 크지만 5번째). 두 모드 분리로 명확화.
- **"행성은 스스로 빛난다"** → 태양광 반사임을 명암 표현으로.

## 2. 화면 흐름

```
[인트로] → [모드 허브] ─┬─ 여행 모드(공전 애니메이션)
                        ├─ 크기 비교 모드
                        ├─ 거리 비교 모드
                        └─ 행성 도감(탐방)
                              ↓
                        [미션] → [결과 정리]
```

### 2-1. 인트로
- 미션 카드: "태양계에는 여덟 행성이 있어요. 얼마나 크고, 얼마나 멀까요? 직접 여행해 봐요." + `시작하기`.

### 2-2. 여행 모드 (공전)
- 태양 중심, 8행성이 각자 속도로 공전(안쪽이 빠름 — 케플러 정성 표현). **속도 슬라이더**로 시간 배속 조절, `정지/재생`.
- 행성 탭 → 카메라가 그 궤도로 이동, 도감 진입. 팬/줌으로 태양계 둘러보기.
- 이 모드는 **궤도 간격을 보기 좋게 압축**(실척 아님)하고 라벨로 명시("보기용 간격 — 실제 거리는 '거리 비교'에서").

### 2-3. 크기 비교 모드
- 거리를 무시하고 8행성 + 태양을 **지름 실비율**로 나란히. 지구를 기준(1)으로 배수 표시. 목성·토성의 압도적 크기, 태양 앞의 먼지 같은 지구를 체감.
- 지구를 드래그해 다른 행성 옆에 대보는 "겹쳐 재기" 인터랙션.

### 2-4. 거리 비교 모드
- 크기를 무시(점/작은 원)하고 태양~각 행성 **거리 실비율**을 가로 축에 배치. 화면에 다 안 들어옴 → **가로 스크롤/줌**으로 "이렇게나 멀다"를 몸으로 느끼게. AU 대신 "지구 거리의 몇 배" 정성 라벨.
- 크기 모드에서 이 모드로 토글하는 순간의 "안 맞음"이 핵심 학습 장면 — 전환 시 안내 문구.

### 2-5. 행성 도감 (탐방)
- 행성별 카드: 이모지/인라인 SVG 외형, 한 줄 특징(색·고리·대적점 등), 지구 대비 크기·거리·하루/일년 길이(정성). 저학년 친화 최소 텍스트.

### 2-6. 미션
| # | 유형 | 예 |
|---|------|----|
| ① 순서 | 8행성을 태양에서 가까운 순으로 배열 | 수·금·지·화·목·토·천·해 |
| ② 크기 | "가장 큰 행성은?" / "지구보다 작은 행성 고르기" | 목성 / 수성·화성 |
| ③ 거리 | "지구보다 태양에서 먼 행성은?" 다중 선택 | 화성 밖 전부 |
| ④ 개념 | "행성은 왜 빛날까?"(태양빛 반사) 3지선다 | |
- 예측→확인: 배열/선택 후 정답 모드로 이동해 시각 확인.

### 2-7. 결과 / 배움 정리
- 정리 카드: "태양계엔 여덟 행성이 있어요. **크기와 거리는 함께 그릴 수 없을 만큼** 차이가 커요. 행성은 태양빛을 반사해 빛나요."
- `다시` / `허브` / 공유(즐겨찾는 행성/현재 뷰).

## 3. 기술 설계

### 3-1. 렌더링
- **SVG 또는 Canvas 2D**(외부 CDN 0). 공전 애니메이션은 각도 갱신 + transform, requestAnimationFrame 단일 루프.
- 행성 외형은 인라인 SVG(고리·색·명암 그라디언트) — 외부 이미지 요청 없음. 태양광 반사 = 방향성 명암.
- 크기/거리 모드는 동일 데이터에 **스케일 함수만 교체**(size scale ↔ distance scale)로 구현 — 두 모드가 같은 소스에서 파생됨을 코드로도 보장.
- 거리 모드 스크롤/줌: viewBox 팬·줌 또는 CSS transform.

### 3-2. 데이터 모델
```
planets = [ { id, name, emoji, diameterEarth, distanceEarth,
              dayLen, yearLen, colorVars, ring? }, ... ]   // 정적 상수
state = {
  mode: 'travel' | 'size' | 'distance' | 'codex',
  timeScale, playing, camera:{x,y,zoom},
  progress:{ missions:{...}, favorites:[id...] }
}
```
- 데이터 출처는 실측 상대값(지구=1 정규화)을 상수로 하드코딩. 정확성 표는 문서 부록/주석으로 근거 남김.

### 3-3. 저장 · 공유
- `localStorage` 키: `solar-system:v1` → `{ missions, favorites, settings }`.
- 공유: `#share=` payload `{ v:1, mode, focusPlanet }` — 특정 행성/뷰 공유. `shareCurrentPage()` 단축링크.

### 3-4. 의존성
- 외부 CDN 0. 오프라인 완전 동작.

## 4. 디자인

- 공통 3종 + 표준 스크립트, `immersive` 셸(우주 다크 배경 친화).
- 팔레트: `--ss-space`(배경), 행성별 색 변수, `--ss-orbit`(궤도선), `--ss-scale`(비교 눈금). 색+라벨 병용.
- 행성 탭/드래그 타깃 ≥ 44px. 모드 전환 탭은 상단 고정.
- 라이트모드에서도 궤도선·행성 대비 확인(우주 배경이라 다크가 기본이나 강제 아님).

---

## 5. 스코프 제한 (Non-goals)

- 위성(달 제외)·소행성대·혜성 개별 표현은 v1 제외(언급 수준). 별자리·별의 밝기/색은 확장 여지(`v` 필드).
- 궤도 이심률·경사·실제 위치(에페메리스) 없음 — 원궤도 정성 표현.
- 3D 엔진/실사 텍스처 없음(외부 CDN 0 유지).
- 크기·거리를 한 화면에 실척 동시 표시 시도 없음(불가능 — 모드 분리가 설계 의도).

## 6. 제작·배포 절차

1. 스캐폴드:
   ```bash
   node scripts/scaffold-app.js --id solar-system --name "태양계 여행" --base immersive \
     --category edu --subcategory edu-sim --emoji 🪐 --desc "여덟 행성 공전·크기·거리 비교와 행성 도감"
   ```
2. `apps.json` 수동 보강: `badge: "시뮬레이션"`, SEO:
   - `seo.title`: `태양계 여행 — 행성 공전·크기·거리 비교 시뮬레이션`
   - `seo.description`: `여덟 행성을 공전시키고 크기와 거리를 실제 비율로 비교해 보세요. 행성 도감과 퀴즈까지, 초등 5~6학년 태양계와 별을 체험하는 무료 학습 시뮬레이션.`
   - `seo.keywords`: `태양계`, `행성`, `행성 크기 비교`, `행성 거리`, `태양계와 별`, `초등 과학`
3. 구현 → `npm run dev` → `npm run inject` → `npm run og` → `npm run sitemap` → 커밋.

## 7. 검수 체크리스트

- [ ] 크기 비교 모드의 지름 비율과 거리 비교 모드의 거리 비율이 각각 실측 상대값과 일치하는가 (데이터 정확성)
- [ ] 두 모드 전환 시 "함께 그릴 수 없음"이 안내 문구로 명시되는가 (설계 대원칙)
- [ ] 여행 모드의 "보기용 간격"이 실척 아님을 라벨로 밝히는가 (거리 오개념 차단)
- [ ] 공전 속도가 안쪽 행성일수록 빠른가 (정성적 케플러)
- [ ] 행성이 태양빛 반사로 빛남이 명암으로 표현되는가
- [ ] 거리 모드 스크롤/줌이 태블릿에서 매끄럽고 광활함이 체감되는가
- [ ] 8행성 순서·크기·거리 미션 정답 판정이 정확한가
- [ ] 다크/라이트 대비·포커스 링·공유 복원 정상
- [ ] inject/og/sitemap 산출물 정상 (개발 가이드 §7 공통 체크 포함)

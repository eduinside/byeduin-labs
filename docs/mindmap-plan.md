## 3. 화면 구성

### 3.1 홈(목록) - 칠판 홈과 같은 카드 격자
- 상단: `+ 새 마인드맵`, `AI로 초안 만들기`, `마크다운 가져오기`(붙여넣기·.md 파일)
- 카드: 제목, 가지 수, 수정일, 미리보기(가운데 주제 + 첫 가지 3개 글자)
- 카드 버튼: **보기**(전체 화면), **편집**, 더보기(복제·이름 바꾸기·지우기·공유·MD로 보내기)
- 동기화 상태 표시는 칠판과 같은 VivesSync 마운트(코드 6자리)

### 3.2 편집 화면
- Mind Elixir 편집 모드. 도구 막대: 홈으로, 제목, 가지 추가(Tab)·형제 추가(Enter)·지우기, 되돌리기, 화면 맞춤, 좌우/오른쪽 펼침 전환, 테마(밝게/칠판 어둡게), 보기, 공유, MD로 보내기
- 처음 쓰는 사람용 짧은 단축키 안내(Tab 가지, Enter 형제, F2 고치기, Space 접기)
- 자동 저장(localStorage, 1초 디바운스) → VivesSync가 서버로 올림

### 3.3 보기 - 칠판처럼 화면 가득 (구현 중 운영자 결정으로 바뀜)

**구현 결과(운영자 결정 2026-10-31)**
- 맵 화면 자체가 이미 화면 가득이라 별도 전체 화면(Fullscreen API) 보기 모드는 두지 않는다. 카드의 '보기'는 맵을 연다.
- 상단 막대는 칠판 앱(#cb-tb)과 같은 모양·색. 밝은 색 = 화이트보드(#ebebea/#f7f7f4), 칠판 색 = 칠판(#122418/#1a3323). 900px 아래에서는 버튼 글자를 빼고 아이콘만(칠판 앱도 같게 고침).
- 빈 곳을 마우스 왼쪽으로 끌면 화면 이동(손 모양 커서). Mind Elixir 5.15.1은 편집 중 빈 곳 왼쪽 누름을 늘 상자 고르기로 받아서, capture 단계에서 먼저 받아 `mind.move()`로 직접 옮긴다.
- 배율: 오른쪽 아래 지도 앱식 +/− (30%~300%). 휠·두 손가락 확대도 그대로.
- 가지는 가운데 주제 아래 **5단계까지**(`MindmapMD.MAX_DEPTH`). 편집기는 `before` 훅(addChild·insertParent·moveNode*)으로 막고, 마크다운·AI 초안은 더 깊은 줄을 5단계에 나란히 붙인다.
- 가지를 끌어 가운데 주제에 놓기: Mind Elixir는 부모 없는 노드를 놓을 곳으로 받지 않아, 끌기 유령이 보일 때 가운데 주제 위에서 놓으면 `moveNodeIn(…, root)`로 큰 가지로 옮긴다.
- 공유받은 '보기 전용' 맵은 편집 도구를 숨기고 고칠 수 없게 연다. 복제 허용 링크에서 '보기만'을 고르면 막대에 '내 목록에 담기'.

**처음 계획(참고)**
- `보기` 누르면 `requestFullscreen()` + `editable:false` + 화면 맞춤. 전자칠판·TV 수업용
- 큰 글씨 배율 조절(+/−), 가지 클릭으로 펼치기/접기(하나씩 펼쳐 가며 설명), 마우스 끌어 이동·휠 확대
- `Esc` 또는 닫기 버튼으로 나가면 원래 화면(목록 또는 편집)으로
- 전체 화면을 지원하지 않는 기기(iOS 사파리)는 화면 가득 채우기(CSS)로 대체

## 5. 공유 (단축 링크)

- vives-share 패턴 그대로: `#share=` + `VUI.share.encode({ data, permission })` → `VUI.share.link()`가 `/api/shorten`(short.io)으로 줄여 복사
- 보내는 데이터는 **마크다운 개요 문자열**(아래 6절 형식). JSON보다 훨씬 짧아 링크가 덜 길어짐. 색·접힘 같은 꾸밈은 보내지 않음(1단계)
- 권한: `보기 전용`(받은 사람은 바로 보기 화면) / `복제 허용`(내 목록으로 가져오기 모달)
- 링크 상한 8000자(MD 편집기와 같음). 넘으면 "가지가 많아 링크로 보낼 수 없어요. MD로 보내서 파일로 전달해 주세요." 안내

## 6. 마크다운 변환 규칙 (마인드맵 ↔ MD 공용)

마인드맵 → MD:
```md
<!-- mindmap -->
# 광합성
- 재료
  - 이산화탄소
  - 물
- 조건
  - 빛
- 결과물
  - 포도당
  - 산소
```
- 가운데 주제 = `# 제목`, 가지 = 들여쓰기 2칸 목록. 첫 줄 `<!-- mindmap -->` 표시(미리보기에 안 보임)
- 노드 글의 줄바꿈은 공백으로, 메모가 있으면 다음 줄 `  > 메모`(2단계)

MD → 마인드맵 (받을 때):
- `#`~`######` 제목과 `-`/`*`/`1.` 목록을 하나의 트리로 해석. 제목 아래 목록은 그 제목의 자식
- `#`이 없으면 파일 이름(또는 첫 줄)을 가운데 주제로
- 본문 문단·표·코드 블록은 버리고, 버린 것이 있으면 "문단·표는 빼고 가져왔어요" 안내

**마인드맵 콘텐츠 판단(MD 편집기에서 쓰는 규칙)**
1. 첫 줄이 `<!-- mindmap -->`이면 무조건 마인드맵
2. 아니면: 제목+목록 줄이 전체 내용 줄의 80% 이상, 항목 5개 이상, 깊이 2단계 이상, 표·코드 블록 없음

변환기는 `public/apps/mindmap/md.js` 한 파일(`window.MindmapMD = { toMd, fromMd, isMindmap }`)로 두고 MD 편집기도 이 파일을 불러 쓴다(규칙 하나로 통일).

## 7. 앱 사이 보내기

| 방향 | 방법 | 위치 |
|---|---|---|
| 마인드맵 → MD 편집기 | QR 앱과 같은 방식: `location.href = /apps/md-editor/#share=` + `{ data:{content, filename:'제목.md'}, permission:'clone' }` | 마인드맵 편집 화면·카드 더보기 `MD로 보내기` |
| MD 편집기 → 마인드맵 | `isMindmap(mdContent)`가 참일 때만 `마인드맵으로 보내기` 메뉴 표시 → `/apps/mindmap/#share=`(`permission:'clone'`) → 마인드맵에서 복제 모달 없이 바로 새 맵으로 추가하고 편집 화면 | MD 편집기 공유 드롭다운(또는 보내기 메뉴) |

- 같은 사이트 안 이동이라 단축 링크를 거치지 않음. 링크 길이 상한을 넘으면 `sessionStorage` 한 번 쓰기로 넘김(`#from=md` 표시)
- MD 편집기 수정은 메뉴 항목 하나 + `md.js` 로딩만. 기존 공유 코드는 건드리지 않음

## 8. AI 초안 (플래시 카드 방식)

- 버튼 `AI로 초안 만들기` → 모달: 주제(필수, 200자), 대상(초등 저학년/고학년/중등/일반), 가지 깊이(2~3단계)
- `POST /api/mindmap-draft { topic, level, depth }` → `{ markdown }`
  - `_guard.js`에 `'mindmap-draft': { perMin: 30, perDay: 300, siteDay: 1000 }` 추가(플래시 카드와 같은 크기)
  - `generateContent()`(Timely 기본 모델 → Gemini 폴백), temperature 0.7
  - 프롬프트: 6절 MD 형식으로만 출력, 가운데 주제 1개, 큰 가지 4~6개, 가지당 2~4개, 한 노드 15자 안팎, 대상 눈높이 낱말
  - 서버에서 코드 블록 제거 → `fromMd()`로 검증(노드 3개 미만이면 오류 응답)
- 결과는 바로 저장하지 않고 미리보기 → `이대로 만들기` / `다시 만들기`
- 오류·한도 초과 문구는 `_ai.js`의 사용자용 문구 그대로

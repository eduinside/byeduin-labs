### 잡아야 할 오개념
1. **그림자가 가장 짧은 때는 낮 12시** → 대구에서는 대략 12시 10분~12시 40분(경도와 균시차 때문). 시각을 읽어 확인하게 한다.
2. **태양 고도가 가장 높을 때 기온도 가장 높다** → 기온은 오후 2~3시 무렵이 가장 높다.
3. **여름에는 지구가 태양에 가까워서 덥다** → 지구는 1월 초에 태양과 가장 가깝다. 모드 3에서 거리도 함께 보여 준다.
4. **그림자는 늘 같은 방향** → 오전엔 서쪽, 남중 때 북쪽, 오후엔 동쪽으로 돈다.

## 2. 계산 모델

| 항목 | 방법 |
|---|---|
| 장소 | 기본 대구(북위 35.87°, 동경 128.60°). 서울(37.57°, 126.98°), 제주(33.50°, 126.53°) 선택 — 위도에 따라 남중 고도가 달라짐을 보이는 정도 |
| 태양 적위·균시차 | The Astronomical Almanac 저정밀식(태양 황경·적경, 약 0.01°). 처음 쓴 NOAA 분수 연도식은 춘·추분 무렵 고도 0.3°, 일출 3분 차이가 나서 바꿈 |
| 시각 | 화면 시각은 한국 표준시. 태양시 = 표준시 + 4분 × (경도 − 135) + 균시차 |
| 태양 고도·방위 | sin h = sin φ sin δ + cos φ cos δ cos H, 방위는 같은 식에서. 대기 굴절은 무시 |
| 일출·일몰, 낮의 길이 | 고도 −0.833°가 되는 시각 |
| 그림자 | 길이 = 막대 길이 ÷ tan h (h ≤ 0이면 그림자 없음, "밤"), 방향 = 태양 방위 + 180° |
| 기온 | 기상청 기후 평년값(1991~2020) 해당 지점의 월별 일최고·일최저기온으로 하루 곡선을 만든다. 최저는 일출 무렵, 최고는 14~15시. 화면에 "평년값으로 만든 보기 자료"라고 밝힌다. 숫자는 구현할 때 기상청 자료에서 옮기고 `climate.json`에 출처를 적는다 |

| 날 | 남중 시각 | 남중 고도 | 낮의 길이 | 1m 막대 남중 그림자 |
|---|---|---|---|---|
| 춘분 3/20 | 12:33 | 53.9° | 12시간 7분 | 0.73 m |
| 하지 6/21 | 12:27 | 77.6° | 14시간 36분 | 0.22 m |
| 추분 9/23 | 12:18 | 54.1° | 12시간 8분 | 0.72 m |
| 동지 12/22 | 12:24 | 30.7° | 9시간 43분 | 1.68 m |

- 2026-10-06 대조: PyEphem(VSOP87, 해 중심 −50′ 기준)과 비교해 대구·서울·제주의 하지·동지·춘분·추분, 일출·일몰·남중 시각은 모두 1분 이내, 남중 고도는 0.1° 이내.

- 남중 시각은 1년 동안 대략 12:09~12:40 사이에서 움직인다.
- 한국천문연구원 자료와의 직접 대조는 하지 못했다(자동 조회 불가). 대신 위 PyEphem 대조로 갈음.
- 교과서 수치(대개 서울 기준)와 다를 수 있으므로 장소를 화면에 항상 표시한다.

## 3. 화면 흐름

```
[인트로] → 모드 탭 [① 하루 관찰] [② 계절 비교] [③ 계절의 원인] ⇄ [미션] → [결과]
```

### 3-1. 모드 1 — 하루 관찰 [6과13-01]
- **장면**: 비스듬히 내려다본 운동장(타원 바닥) 위 태양 고도 측정기(막대 + 실 + 각도기), 하늘의 태양 경로 호, 바닥의 그림자. 방위 글자(동·서·남·북). moon-phase-v2와 같은 2D 유사 3D 방식(SVG).
- **조작**: 시각 슬라이더(일출~일몰, 10분 단위) + ▶ 재생(1초 = 30분), 날짜(기본 오늘, 달력에서 고르기), 장소.
- **표시**: 태양 고도(각도기에 실이 가리키는 각), 그림자 길이, 기온.
- **측정 기록**: [측정하기]를 누르면 지금 값을 표에 적는다(교과서처럼 9:30~15:30 매시 30분 권장, 자유 시각도 됨). 기록이 3개 이상이면 꺾은선그래프 3개(태양 고도·그림자 길이·기온)를 `VGraph.line`으로 그린다.
- **발견 질문**: "그림자가 가장 짧은 때는 언제인가요?", "기온이 가장 높은 때는 태양 고도가 가장 높은 때와 같나요?"

### 3-2. 모드 2 — 계절 비교 [6과13-02]
- 날짜 슬라이더(1년) + 절기 버튼(춘분·하지·추분·동지).
- 하늘에 네 절기의 태양 경로를 겹쳐 그리고, 고른 날은 진하게. 일출·일몰 방위가 계절마다 바뀌는 것도 보인다.
- 표: 절기별 남중 고도, 낮의 길이, 남중 때 그림자 길이.
- 그래프: 월별(15일 기준) 남중 고도와 낮의 길이 꺾은선 2개 → 같이 오르내리는 것을 확인.
- **빛 실험**: 손전등을 기울이는 장면. 같은 양의 빛이 비추는 바닥 칸 수가 고도가 낮을수록 늘어남 → 한 칸이 받는 빛이 줄어 덜 따뜻함(남중 고도와 기온의 관계).

### 3-3. 모드 3 — 계절의 원인 [6과13-03]
- 위에서 본 공전 궤도 위 지구 4곳(절기)과 옆에서 본 지구(자전축, 북위 36° 지점에 서 있는 사람, 정오의 햇빛 각도).
- **자전축 기울기 토글**: 23.5° ↔ 0°. 0°로 바꾸면 1년 내내 남중 고도·낮의 길이가 같아져 계절이 생기지 않음을 그래프로 비교.
- 지구–태양 거리 표시(1월 초 가장 가까움) → 오개념 3.
- 공전 궤도는 원에 가깝게 그리고 "실제로는 거의 원"이라고 적는다(타원을 과장하지 않음).

### 3-4. 미션 (SimKit, 8개 — 예측 먼저, 확인은 그다음)
| # | 미션 | 확인 방법 |
|---|---|---|
| m1 | 오늘 그림자가 가장 짧아지는 시각 찾기 | 슬라이더로 찾아 [이때!] → ±10분이면 정답 |
| m2 | 1m 막대의 그림자가 1m가 되는 시각 찾기(고도 45°) | 같은 방식. 해당 날짜에 45°에 못 미치면 다른 날짜를 줌 |
| m3 | 기온이 가장 높은 시각 예측 → 확인 | 보기 3개(12시·14시·17시) |
| m4 | 오후 3시 그림자 방향 고르기 | 방위 4개 |
| m5 | 하지와 동지의 남중 고도 비교 예측 → 확인 | 보기 |

| m7 | 손전등을 세울수록 비추는 칸 수는? | 보기 |

- 별: 첫 시도 정답 ★3, 두 번째 ★2, 그 외 ★1. 예측을 고르기 전에는 확인 버튼이 잠긴다(volcano·fraction-bar와 같은 원칙).

### 3-5. 태블릿 조작
- 학생 태블릿 손가락 조작이 기본. 셸은 기존 시뮬레이션 관행대로 `immersive`.

## 8. 구현 메모 (2026-10-06)

- 기온 평년값(`public/apps/sun-shadow/climate.json`): 기상청 1991~2020 월별 일평균 최고·최저기온. 대구·서울·제주 모두 위키백과 한국어·영어판 기후표(출처 기상청) 두 곳에서 같은 값인지 대조. 각 달 15일 값을 직선으로 이어 날짜별 최고·최저를 정하고, 일출 때 최저 → 14:30 최고 → 다음 일출로 내려가는 곡선.
- 하늘 그림은 가로를 동서, 높이를 고도에 비례하게 그림(그냥 반구 투영이면 하지·춘분의 남중 높이 차이가 작게 보여서). 그림자 길이·방향은 실제 계산값.
- 미션 1(그림자가 가장 짧은 때)은 남중 ±20분을 정답으로 봄. 남중 앞뒤 20분은 1m 막대 그림자 차이가 1cm도 안 돼 학생이 구별할 수 없음. 미션 화면은 그림자를 0.1cm까지 보여 줌.
- 계절의 원인 모드의 적위는 sin δ = sin(기울기) × sin(태양 황경)으로 계산해, 기울기 0°이면 1년 내내 남중 고도가 같음(대구 54.1°).
- 측정 기록은 그날 하루치만 저장(날짜가 바뀌면 비움).

# food-bike — 식품구성자전거 개발문서

> 작성: 2026-07-04 · 작성자: Claude Fable 5 · 상위 기획: [simulation-apps-plan.md](simulation-apps-plan.md) (실과 라인 신규 후보 — 검토 후 실과 라인 최우선으로 배치)
> 제약: 순수 정적 SPA(단일 HTML) · localStorage만 사용 · 외부 의존성 0(폰트 제외)

## 설계 대원칙 (위반 시 반려 — 이 앱의 성패 조건)

1. **"좋은 음식/나쁜 음식" 이분법 금지.** 판정 축은 오직 **6개 식품군의 균형(비율)**. 유지·당류도 "적게 먹는 군"일 뿐 "나쁜 음식·금지"로 표현하지 않는다. 개별 음식에 대한 부정 낙인(X 표시·빨간 금지선·"나빠요" 문구) 일절 없음.
2. **칼로리·체중·다이어트 프레이밍 절대 배제.** 열량 수치, "살찌는", "날씬", 체중·체형 언급 금지. 자전거가 "무거워진다"는 표현도 몸이 아니라 **자전거 짐칸**에 비유(몸 은유 회피).
3. **현행 교과서 버전 고정 + 출처 명시.** 식품군 구성·명칭은 한국영양학회 식품구성자전거의 **현행 교과서 수록판** 기준(6개 식품군: 곡류 / 고기·생선·달걀·콩류 / 채소류 / 과일류 / 우유·유제품류 / 유지·당류 + 앞바퀴 물 + 신체활동). 구현 착수 시 실제 교과서 도판과 대조해 명칭·비율을 데이터 상수에 주석으로 근거 기재.
4. **식이 다양성 중립.** 특정 음식 강요 없음("우유를 꼭 마셔요" 대신 "우유·유제품류에는 이런 음식이 있어요"). 알레르기·종교·채식 관련 음식은 대체 예시가 항상 함께 노출되도록 음식 카드 풀을 구성.

## 1. 개요

| 항목 | 값 |
|------|-----|
| 앱 ID | `food-bike` (`/apps/food-bike/`) |
| 이름 · 이모지 | 식품구성자전거 · 🚲 |
| 셸 | `immersive` (자전거+접시 무대가 뷰포트 소유, 게임식 연출) |
| 카테고리 | `edu` / `edu-sim` · 배지 `시뮬레이션` |
| 한 줄 | 음식을 접시에 담아 자전거 바퀴를 채우고, 균형 잡힌 식단이면 자전거가 신나게 달리는 식생활 게임 |
| 교과 | 실과 5~6학년 「식생활」(균형 잡힌 식사, 식품구성자전거) |
| 대상 기기 | 태블릿·크롬북·스마트폰 |

### 교과 근거 (2022 개정, 실과 5~6학년 가정생활 「식생활」)
- 균형 잡힌 식사의 필요성과 방법 이해
- 식품구성자전거: 6개 식품군과 섭취 비율(뒷바퀴 면적), 물(앞바퀴), 신체활동(자전거 타기)
- 식품을 식품군으로 분류하고 끼니 식단을 균형 있게 구성

### 학습 목표
1. 음식을 6개 식품군으로 분류한다.
2. 균형 잡힌 식사란 **여러 식품군을 알맞은 비율로** 먹는 것임을 안다(많이 먹는 군/적게 먹는 군의 비율 차).
3. 물과 신체활동도 건강한 식생활의 일부임을 안다(앞바퀴·자전거의 의미).
4. 주어진 식단에서 부족한 식품군을 찾아 보완한다.

### 오개념 교정 포인트
- **"고기(단백질)만 많이 먹으면 좋다"** → 한 군만 커진 바퀴는 찌그러져 못 달림.
- **"채소만 먹는 게 제일 건강하다"** → 마찬가지로 균형 붕괴 연출(어느 군이든 독식은 비틀거림 — 판정이 대칭적이라 대원칙 1과 정합).
- **"물·운동은 식생활과 무관"** → 앞바퀴(물)가 비면 자전거가 출발 못 함, 페달(활동)의 의미 카드.

## 2. 화면 흐름

```
[인트로] → [자유 탐험: 식단 꾸미기] → [미션 4종] → [결과 정리]
```

### 2-1. 인트로
- 미션 카드: "자전거 바퀴를 골고루 채우면 신나게 달릴 수 있대요! 오늘의 식단을 만들어 볼까요?" + `시작하기`.

### 2-2. 자유 탐험 — 식단 꾸미기 (핵심 게임 루프)
- **무대(상단)**: 식품구성자전거 — 뒷바퀴 6분할(교과서 비율의 부채꼴), 앞바퀴(물), 라이더 캐릭터.
- **접시(중단)**: 내가 담은 음식 카드들이 놓이는 하루 식단 접시.
- **음식 카드 팔레트(하단)**: 음식 40여 종(이모지+이름). 밥·빵·국수(곡류), 두부·달걀·생선·닭고기(단백질군), 시금치·당근(채소), 사과·귤(과일), 우유·치즈·요거트(유제품), 참기름·설탕(유지·당류), 물·보리차(앞바퀴) 등. **탭 또는 드래그로 접시에 담기/빼기.**
- **즉시 피드백(게임성의 핵심)**:
  - 접시 구성에 따라 뒷바퀴 각 부채꼴이 채워짐(그 군을 담은 만큼 게이지↑).
  - **균형 게이지**: 6군이 교과 비율에 가깝게 차면 자전거가 경쾌하게 페달을 밟으며 배경이 흐르는 주행 애니메이션(속도 = 균형도). 한 군이 비면 그 바퀴 구역이 찌그러져 **비틀비틀** 이동. 유지·당류가 비율을 크게 초과하면 **짐칸에 짐이 쌓여** 천천히(몸 아닌 짐 은유 — 대원칙 2).
  - 물 미담기 → 앞바퀴가 바람 빠져 출발 못 함 + "앞바퀴는 물이에요!" 안내.
  - 부족/과잉 군은 문구로 안내하되 **항상 "더 담아 볼까요?" 톤**(빼기 강요·부정 낙인 없음).

### 2-3. 미션 (4종)
| # | 유형 | 내용 |
|---|------|------|
| ① 분류 | 음식 카드 10장을 6개 식품군 바구니로 분류 — 헷갈림 유도 카드 포함(두부→고기·생선·달걀·**콩류**, 감자→곡류, 토마토→채소류) |
| ② 고치기 | 불균형 식단 제시(예: 곡류+유지·당류만) → "무엇을 **더하면** 균형이 잡힐까요?" 채소·과일·단백질군 담아 자전거 달리게 하기 — **빼기가 아니라 더하기로 해결하는 문제를 기본**으로(대원칙 1) |
| ③ 한 끼 만들기 | 자유 재료로 아침 한 끼를 균형 있게 구성 → 균형 게이지 통과 기준 |
| ④ 식단 비교 | 대표 식단 2~3개(학교 급식 한 상 vs 빵+음료 간편식 등)를 바퀴 2개로 나란히 → "어느 군이 비어 있나요?" 찾기. 특정 식단 비하 없이 **"무엇이 빠졌고 무엇을 더하면 되는지"**로 서술 |
- 예측→확인 원칙: ②④는 답을 고른 뒤 바퀴/주행 연출로 확인.
- 별점: 첫 시도 정답 ★3 기준(기존 앱들과 동일).

### 2-4. 상식 카드 (미션 사이 삽입)
- 앞바퀴는 왜 물일까? / 자전거를 타는 이유(신체활동) / 식품군별 대표 음식 한 줄 — 3~5장, 넘기기식. 교과서 서술 톤 유지.

### 2-5. 결과 / 배움 정리
- 별점 + 정리 카드: "건강한 식사는 **여러 식품군을 알맞은 비율로 골고루** 먹는 거예요. 물과 몸을 움직이는 것도 잊지 마세요!"
- `다시` / `식단 꾸미기로` / 공유(내가 만든 식단).

## 3. 기술 설계

### 3-1. 균형 판정 (정성, 대원칙 준수 검증 지점)
```
foodDB = [ { id, name, emoji, group, unit } ]        // group: 1~6 + 'water'
교과 비율(뒷바퀴 부채꼴) = groupTarget[6]             // 교과서 도판 기준 상수, 출처 주석
접시 상태 plate = { counts: [군별 담은 unit 합], water: n }
```
- **군별 게이지** = counts ÷ 군별 권장 unit(간이 상수) — 수치 미노출, 부채꼴 채움으로만 표현.
- **균형도** = 6군 게이지의 최소값 기반(가장 부족한 군이 속도를 결정 — "골고루"의 직접 표현) + 유지·당류만 상한 초과 시 감속 페널티. 물 미담기는 출발 게이트.
- 판정 결과는 3단계(쌩쌩/보통/비틀비틀) + 부족 군 목록. **점수·등수·열량 없음.**
- ①분류 미션 정답표는 foodDB의 group 필드 그대로(단일 소스).

### 3-2. 렌더링
- **SVG**: 자전거(바퀴 부채꼴 6분할 `<path>`, 채움 게이지는 반지름 방향 클리핑), 주행은 배경 요소 CSS 트랜슬레이트 루프 + 바퀴 회전. 찌그러짐은 해당 부채꼴 스케일 변형.
- 음식 카드는 이모지+라벨(외부 이미지 0). 담기/빼기는 **탭 우선**(드래그는 보조) — 이 앱은 연결선이 없어 탭만으로 완결되므로 `/common/drag-connect.js` 의존 없이 착수 가능. 드래그를 넣는 경우에도 탭 폴백이 기본(접근성 원칙 자동 충족).

### 3-3. 저장 · 공유
- `localStorage` 키: `food-bike:v1` → `{ missions, lastPlate, settings }`.
- 공유: `#share=` payload `{ v:1, plate }` — "내가 만든 식단" 공유. 수신 측은 그 접시가 담긴 무대로 진입. `shareCurrentPage()` 단축링크. 진도 미포함.

### 3-4. 의존성
- 외부 CDN 0. 오프라인 완전 동작.

## 4. 디자인

- 공통 3종 + 표준 스크립트, `immersive` 셸.
- 팔레트: 식품군 6색을 `:root` 변수로(교과서 도판 색 계열 참고) + **색+아이콘+군 이름 라벨 병용**(색약 대비). `--fk-go`(주행), `--fk-wobble`(비틀), `--fk-water`(앞바퀴).
- 음식 카드·군 바구니 터치 타깃 ≥ 44px. 저학년 겸용 대비 텍스트 최소·이모지 크게.
- 다크모드에서 부채꼴 채움/빈 영역 대비 확인.

## 5. 스코프 제한 (Non-goals)

- **열량·영양소 수치(g·kcal·비타민 표) 없음** — 군 단위 정성 게이지만(대원칙 2·3).
- 개인 식단 기록·연속 일수 추적 없음(습관 추적은 민감 — 세션 내 놀이로 한정).
- 음식 사진·브랜드 제품 없음(이모지 일반명만). 국가별 식단 비교 없음.
- 알레르기 정보 제공 기능 없음(의학 정보 영역 — 단, 카드 풀에 대체 예시 병존은 유지).

## 6. 제작·배포 절차

1. 스캐폴드:
   ```bash
   node scripts/scaffold-app.js --id food-bike --name "식품구성자전거" --base immersive \
     --category edu --subcategory edu-sim --emoji 🚲 --desc "음식을 담아 바퀴를 채우는 균형 식단 게임"
   ```
2. `apps.json` 수동 보강: `badge: "시뮬레이션"`, SEO:
   - `seo.title`: `식품구성자전거 — 균형 잡힌 식단 만들기 게임`
   - `seo.description`: `음식을 접시에 담아 식품구성자전거 바퀴를 채워 보세요. 6개 식품군을 골고루 담으면 자전거가 신나게 달려요. 초등 실과 식생활을 체험하는 무료 학습 시뮬레이션.`
   - `seo.keywords`: `식품구성자전거`, `식품군`, `균형 잡힌 식사`, `실과 식생활`, `초등 실과`, `식단 게임`
3. **콘텐츠 게이트**: 구현 전 foodDB(음식 40종·군 분류)와 군별 비율 상수를 현행 교과서 도판과 대조 확정(대원칙 3). 분류 애매 음식(감자·토마토·옥수수 등)은 교과서 기준으로 통일하고 주석 기재.
4. 구현 → `npm run dev` → `npm run inject` → `npm run og` → `npm run sitemap` → 커밋.

# world-landmarks — 「조사 보고서 만들기」 모드 추가 계획서

> 작성: 2026-07-13 · 상위 문서: [world-landmarks-plan.md](world-landmarks-plan.md) (v1 세계 탐험대)
> 제약: 순수 정적 SPA(기존 `index.astro` 단일 파일에 추가) · localStorage만 사용 · 서버/DB 없음
> 목적: 학생이 **앱을 보면서 종이(또는 문서) 조사 보고서를 직접 작성**하도록 돕는 "탐색 보조" 모드

---

## 1. 개요

| 항목 | 값 |
|------|-----|
| 대상 앱 | `world-landmarks` (`/apps/world-landmarks/`) |
| 추가 모드 | 📝 조사 보고서 만들기 (기존 🛫 탐험 여권 만들기와 병렬) |
| 셸 | 기존 `immersive` 셸 유지 — 단, 조사 모드 화면은 **일반 스크롤 문서형 레이아웃**(지도 없음) |
| 대상 | 초등 3~6학년 사회과 "세계 여러 나라" 조사 학습 · 태블릿/크롬북/PC |
| 한 줄 | 대륙별로 고르게 배분된 세계 여러 나라의 국기·위치·수도·인사말·음식·자랑거리·문화를 카드형으로 소개하고, 소주제별 유튜브·네이버 검색 링크로 추가 조사를 잇는 조사 보고서 도우미 |

### 기존 모드와의 관계

| | 🛫 탐험 여권 만들기 (기존) | 📝 조사 보고서 만들기 (신규) |
|---|---|---|
| 형식 | 전체화면 3D 지도 이머시브 | 스크롤 문서형(지도 없음) |
| 중심 | 랜드마크 관찰 + 퀴즈 + 도장 | 나라별 정보 탐색 + 외부 조사 링크 |
| 나라 수 | 11개국 고정 | 11개국 포함 **24개국** (대륙 배분) |
| 산출물 | 여권(앱 내 도장) | 학생이 직접 쓰는 보고서(앱 밖) — 앱은 조사 진행 체크만 저장 |
| 수업 장면 | 저학년 문화 다양성 체험 | 중·고학년 조사 학습(모둠별 나라 배정 등) |

두 모드는 **인트로 화면에서 버튼 2개로 분기**하며, 데이터·스타일을 공유하되 화면 흐름은 완전히 독립. 기존 탐험 모드의 동작·저장 키(`world-landmarks:v1`)는 일절 건드리지 않는다.

## 2. 진입 흐름

```
인트로 화면
├── [탐험 여권 만들기 🛫]  → 기존 흐름 그대로 (renderExplore)
└── [조사 보고서 만들기 📝] → 신규 (renderResearch)
      ├── 나라 목록 화면 (대륙 필터 탭 + 나라 카드 그리드)
      └── 나라 상세 화면 (조사 항목 섹션 + 소주제별 조사 링크)
```

- 인트로의 미션 카드도 2단으로: 각 버튼 위에 한 줄 설명("11개 랜드마크를 3D로 탐험" / "24개 나라를 조사해 나만의 보고서 완성").
- 조사 모드에서는 `body.exploring`(overflow hidden)을 쓰지 않는다 — 일반 세로 스크롤.
- URL 해시로 화면 복원: `#research`(목록) / `#research/{countryId}`(상세) — 새로고침·뒤로가기 시 자리 유지, 교사가 특정 나라 링크를 학급에 배포 가능.

## 4. 나라별 조사 항목 (7개 소주제)

각 나라 상세 화면은 아래 7개 섹션 고정. **모든 나라가 같은 뼈대**라서 학생 보고서 양식과 1:1 대응된다.

| # | 소주제 | 앱이 주는 정보 | 조사 링크 |
|---|--------|----------------|-----------|
| 1 | 🏳️ 국기 | 국기 이미지 + 국기에 담긴 의미 1~2문장 | 네이버 이미지("○○ 국기 의미") |
| 2 | 📍 위치 | 대륙·주변 나라 한 문장 + 인라인 SVG 세계지도 위 위치 점 | 네이버("○○ 위치 지도") |
| 3 | 🏛️ 수도 | 수도 이름 + 특징 한 문장 | 유튜브("○○ 수도 여행") · 네이버 이미지 |
| 4 | 👋 인사말 | 원어 인사말 + 한글 발음 + 🔊 읽어주기(TTS, 기존 함수 재사용) | 유튜브("○○어 인사말") |
| 5 | 🍲 대표 음식 | 음식 2가지(이모지 + 한 문장) | 유튜브("○○ 음식") · 네이버 이미지 |
| 6 | 🏆 자랑거리 | 랜드마크·자연·발명품 등 2가지 | 유튜브 · 네이버 이미지(항목명 검색) |
| 7 | 🎎 문화 | 전통 옷·축제·놀이 중 2가지 | 유튜브("○○ 전통 문화") · 네이버 이미지 |

- 문장 프레이밍은 v1 대원칙 계승: "~의 전통 ○○ 중 하나예요" (본질화·우열 비교 금지).
- 섹션마다 우측에 "✅ 조사했어요" 체크 → localStorage 저장(§7). 체크가 곧 진행률.

### 데이터 모델

```js
const COUNTRIES = [
  { id:'kr', nameKo:'대한민국', continent:'asia', flag:{ code:'kr', meaning:'…' },
    capital:{ name:'서울', desc:'…' }, location:{ desc:'…', x:0.78, y:0.38 }, // x,y = SVG 지도 좌표(0~1)
    greeting:{ text:'안녕하세요', roman:'annyeonghaseyo' },
    foods:[{ name:'비빔밥', emoji:'🍚', desc:'…' }, …],
    prides:[{ name:'경복궁', emoji:'🏯', desc:'…' }, …],
    cultures:[{ name:'한복', emoji:'👘', desc:'…' }, …],
    landmarkId:'gyeongbokgung' /* 기존 11개국만 — 탐험 모드 연결 */ },
  …
];
```

## 5. 외부 조사 링크 설계

검색 **결과 페이지로 연결**하는 방식(특정 영상/문서 고정 링크 아님) — 링크가 죽지 않고, 저작권 문제 없이 학생이 직접 고르게 한다.

| 종류 | URL 패턴 | 용도 |
|------|----------|------|
| ▶️ 유튜브 검색 | `https://www.youtube.com/results?search_query={q}` | 영상 조사(여행·음식·문화) |
| 🟢 네이버 통합검색 | `https://search.naver.com/search.naver?query={q}` | 백과·기사 조사 |
| 🖼️ 네이버 이미지 | `https://search.naver.com/search.naver?where=image&query={q}` | 보고서에 붙일 사진 찾기 |

- 검색어는 데이터에 하드코딩하지 않고 **소주제별 규칙으로 생성**(`나라이름 + 소주제 키워드`), 필요한 나라만 `queryOverride`로 예외 지정 — 데이터 중복 최소화.
- 모두 `target="_blank" rel="noopener"`.
- 검색 결과는 앱이 통제할 수 없는 외부 콘텐츠 → 조사 모드 첫 화면에 안내 문구 1줄 고정: "🔗 조사 링크는 외부 사이트로 연결돼요. 선생님·부모님과 함께 살펴보세요." (교실 사용 전제, 유해 콘텐츠 책임 한계 명시)

## 6. 화면 설계

### 6-1. 나라 목록 화면 (`#research`)

- 상단: 제목 + 안내 문구 + **보고서 쓰는 순서 카드**(① 나라 고르기 → ② 7개 항목 살펴보기 → ③ 링크로 더 조사하기 → ④ 보고서에 정리하기).
- 대륙 필터 탭: `전체 | 아시아 | 유럽 | 아프리카 | 북아메리카 | 남아메리카 | 오세아니아` — 탭마다 나라 수 배지.
- 나라 카드 그리드(2~3열 반응형): 국기 + 나라 이름 + 대륙 + 조사 진행률(예: 3/7). 탭 → 상세.

### 6-2. 나라 상세 화면 (`#research/{id}`)

- 헤더: 국기(크게) + 나라 이름 + 대륙 + 수도 한 줄 + (기존 11개국) "🛫 3D로 보기" 버튼.
- 본문: §4의 7개 섹션을 세로로. 각 섹션 = 제목 + 정보 + 조사 링크 버튼 줄 + ✅ 체크.
- 하단: 이전/다음 나라 이동 + 목록으로.
- 진행률 바(7개 중 몇 개 체크) 상단 고정.

### 6-3. 국기 렌더링 전략

v1 계획서가 지적했듯 **Windows Chrome은 국기 이모지를 렌더링하지 못함**. 24개국 국기 SVG를 자체 제작하는 것은 과대 비용(문장 있는 국기 다수) →

- **1안(채택)**: [flagcdn.com](https://flagcdn.com) 이미지 사용(`https://flagcdn.com/w160/{code}.png`). 국기 도안은 저작권 대상이 아니고, 별도 키 없이 무료 CDN. `loading="lazy"` + `onerror` 시 이모지 폴백.
- 다크모드에서 흰 배경 국기(일본 등) 테두리 필수(v1 규칙 계승).
- ⚠️ 기존 탐험 모드도 국기 이모지를 쓰고 있음 — 이번 작업에서 같은 컴포넌트로 교체할지는 **구현 시 별도 커밋**으로 판단(스코프 분리).

### 6-4. 위치 지도

이머시브 3D 지도는 쓰지 않는다. 위치 섹션에 **경량 인라인 SVG 세계지도(간략 실루엣) + 위치 점 + 대륙 하이라이트** 1개만. 외부 타일·라이브러리 로드 없음 → 조사 모드는 MapLibre 없이도 완전 동작(탐험 모드 진입 시에만 지도 로드하도록 스크립트 로드 순서 유지).

## 7. 저장 · 공유

- localStorage 키 신설: `world-landmarks:research:v1` → `{ checks: { [countryId]: ['flag','location',…] } }`. 기존 키와 분리(탐험 모드 무영향).
- 공유(`#share=`)는 v1 범위 외 — 후속에서 vives-share 패턴 적용 검토.

---

## 8. 스코프 제한 (Non-goals)

- 앱 안에서 보고서를 "작성"하는 에디터 없음 — 보고서는 종이/문서에 쓰는 것이 전제. (후속: 인쇄용 보고서 양식 페이지 검토)
- 나라별 실사 사진 내장 없음 — 사진은 검색 링크로 학생이 직접 조사(저작권 0 정책 유지). 국기 이미지는 예외(§6-3).
- 퀴즈·도장 없음 — 조사 모드는 평가가 아니라 탐색 보조.
- 다국어 UI 없음.

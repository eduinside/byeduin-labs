## 2. 화면 구성

### 목록 화면 (chalkboard의 보드 목록과 같은 카드 그리드)
- "우리 반 자리표" 카드: 학급명, 인원, 분단×줄, 마지막 수정일, 미니 배치 미리보기.
- 여러 학급을 따로 관리(교과전담·담임 겸용). `＋ 새 학급`, 카드 메뉴(이름 바꾸기·복제·삭제).
- `JSON 불러오기`: 원본 앱의 백업 파일 형식(`classroom-seating-v2`)을 그대로 받아 새 학급으로 추가 → 기존 사용자가 데이터를 옮겨 올 수 있음.
- 안내 문구: "명단은 이 기기의 브라우저에만 저장돼요. 다른 기기로 옮길 땐 JSON 내보내기를 쓰세요."

### 보드 화면 (전체화면)
- 상단 툴바(chalkboard `#cb-tb` 스타일): ← 목록 · 학급명 · [배열 분단/자유] [책상 1인/2인] [분단 −/+] [줄 −/+] [시점 교사/학생] · 🎲 랜덤 배치 · 되돌리기 · 기준 저장 · ↔ 이동 비교 · 🖨 인쇄 · ⛶ 전체화면 · ⋯ 더보기.
- 가운데: 교실 캔버스(1000×700 논리 좌표, 화면에 맞춰 확대·축소). 칠판·교탁 표시는 시점에 따라 위/아래.
- 오른쪽 서랍(접기 가능): 명단 · 제약 · 저장 탭(원본 사이드바와 같은 내용).
- 하단 상태줄: 좌석·학생·배정·미배치 수, 분리 위반 수, 범례, 조작 힌트.
- **발표 모드**: 툴바·서랍을 숨기고 이름을 크게 — 전자칠판에 띄워 학생에게 보여줄 때.

## 3. 원본에서 그대로 가져올 기능
- 명부 일괄 편집(한 줄 한 명, `이름 남/여`), 번호·성별·앞줄 우선·좌석 고정(핀).
- 분단/자유 배열, 1인/2인 책상, 분단 1~6·줄 1~10, 교사/학생 시점.
- 랜덤 배치(고정석 유지, 앞줄 우선, 떨어뜨릴 쌍 회피, 분단별 성별 균형 — 350회 시도 중 최소 점수).
- 자리 클릭→클릭 교환, 빈자리 채우기·비우고 채우기·전체 비우기, 자리 메뉴(비우기·고정·미배치 학생 넣기).
- 기준 저장·이동 비교(화살표)·기준으로 되돌리기, 배치 스냅샷 저장·불러오기·비교 기준, JSON 내보내기/불러오기.
- A4 가로 한 장 인쇄(학급명·시점·날짜·인원 제목).

## 4. 바꾸거나 더하는 것

| 구분 | 내용 | 이유 |
|---|---|---|
| 터치 | HTML5 드래그앤드롭 → **Pointer Events** 끌어 놓기(명단→자리, 자리→자리, 자유 배열 이동). 길게 누르기로 자리 메뉴 | 원본은 마우스 전용 — 전자칠판·태블릿에서 끌기 불가 |
| UI | byeduin 토큰(`--bg`, `--card-bg`, `--border`, `--fg`, `--primary`…)·다크모드·공통 토스트·모달(`VUI`) 사용, Pretendard CDN 제거(공통 글꼴) | 사이트 전체와 통일, 외부 의존 축소 |
| 되돌리기 | 배치 변경 20단계 되돌리기(Ctrl+Z 포함) | 랜덤을 잘못 눌렀을 때 복구 |
| 이전 짝 피하기 | 제약 탭 옵션: 비교 기준(또는 최근 스냅샷)에서 옆자리였던 학생끼리 다시 붙지 않게 점수 반영 | 자리 바꿀 때 가장 흔한 요구 |
| 확인 | 랜덤 배치·전체 비우기·명부 적용으로 배치가 크게 바뀔 때 되돌리기 안내 토스트 | 실수 방지(확인창 남발 대신) |
| 접근성 | 자리는 `button`(aria-label "3행 2열 김민준"), 방향키로 자리 이동·Enter로 선택/교환, 모달 포커스 가두기·ESC, `aria-live` 상태 알림 | 키보드·화면낭독기 |
| 저장 | 키 `vives-seating-v1`(학급 배열), 읽을 때 형식 검증, 용량 초과 시 안내 | 데이터 손상으로 앱이 멈추지 않게 |
| 인쇄 | 학생 이름을 화면보다 크게(자리 칸에 맞춰 최대한 크게, 긴 이름은 자동 축소). 고정(📌)·앞줄(앞) 표시·성별 점·선택/위반/이동 강조·이동 화살표는 인쇄에서 숨김 — 칠판·교탁, 자리 칸, 이름만 | 교실 게시용으로 멀리서도 읽히게(2026-10-05 요청) |
| 개인정보 | 공유 링크·동기화·서버 전송 없음. 예시 명단은 가상의 이름이며 "예시 넣기" 버튼으로만 채움(첫 화면은 빈 학급) | 학생 실명은 기기 밖으로 나가지 않게 |

## 5. 하지 않는 것
- 서버 저장·기기 간 동기화·공유 링크(학생 이름이 담기므로).
- 학생용 화면 공유(QR) — 필요하면 발표 모드로 전자칠판에 띄운다.

## 6. 작업 순서
1. 스캐폴드(`scripts/scaffold-app.cjs`, gallery 셸) → apps.json·OG 이미지·사이트맵 등록.
2. `public/apps/seating/app.js`로 원본 로직 이식(상태·배치 알고리즘은 함수 단위로 그대로, 렌더·이벤트는 새 UI에 맞게).
3. 목록 화면, 보드 화면, 서랍, 발표 모드.
4. Pointer Events 끌기, 되돌리기, 이전 짝 피하기, 키보드 조작.
5. 원본 JSON 가져오기 호환 확인, 인쇄 확인.
6. 빌드·스모크 테스트, 브라우저에서 마우스·터치(에뮬레이션)·다크모드·모바일 폭 확인.
7. OVERVIEW·README 앱 표, 변경 이력 갱신.

## 1. 개요

| 항목 | 값 |
|------|-----|
| 앱 ID | `shape-move` (`/apps/shape-move/`) |
| 이름 · 이모지 | 도형의 이동 · 🔷 |
| 셸 | `immersive` (volcano 동일 — 앱이 뷰포트 소유, 플로팅 크롬만 주입) |
| 카테고리 | `edu` / `edu-sim` · 배지 `시뮬레이션` |
| 한 줄 | 모눈 위 도형을 밀기·뒤집기·돌리기 하며 "이동해도 모양·크기는 안 변한다"를 체득 |
| 교과 | 수학 4학년 「평면도형의 이동」 |
| 대상 기기 | 교실 태블릿·크롬북·스마트폰 (터치 우선, 마우스 겸용) |

### 학습 목표 (성취기준 수준)
1. 밀기·뒤집기·돌리기 후 도형의 위치·방향 변화를 예측하고 확인한다.
2. 세 변환 모두에서 **모양과 크기는 변하지 않음**을 발견한다.
3. 목표 도형을 보고 어떤 변환(들)이 필요한지 역으로 추론한다.

### 오개념 교정 포인트
- "뒤집기와 180° 돌리기는 같다" → **비대칭 도형**으로 차이를 드러냄 (이 앱의 존재 이유).
- "돌리면 크기가 변한다" → 모눈 칸 수 세기로 반증.

## 2. 화면 흐름 (volcano 패턴 이식)

```
[인트로] → [자유 탐험] → [미션 10개] → [결과 정리]
              ↑______________|  (미션 중 언제든 자유 탐험 복귀 가능)
```

### 2-1. 인트로
- 미션 카드: "도형을 움직여도 모양과 크기는 그대로일까요?" + `시작하기` 버튼(`.fd-btn-primary`).
- 조작법 아이콘 3개(밀기/뒤집기/돌리기) 미리보기 애니메이션(CSS 무한루프, 저사양 대비 `prefers-reduced-motion` 시 정지).

### 2-2. 자유 탐험
- **좌(모바일: 상단)**: 8×8 모눈 SVG 캔버스. 도형 1개 + (미션 시) 반투명 고스트.
- **우(모바일: 하단 고정 바)**: 조작 사이드바
  - 도형 선택 4종: `ㄴ자`(기본) · `직각삼각형` · `사다리꼴` · `깃발`(오각형) — 전부 **비대칭**이라 뒤집기·돌리기 차이가 시각적으로 드러남.
  - 버튼: `← → ↑ ↓ 밀기`(1칸 단위) / `좌우 뒤집기` `상하 뒤집기` / `⟳ 90°` `⟲ -90°` / `처음으로`(리셋).
  - 모든 버튼 터치 타깃 ≥ 44px, 아이콘+한글 병기.
- **애니메이션**: 모든 변환 0.4s ease — **순간이동 금지, 궤적이 핵심**. 뒤집기는 축을 점선으로 0.4s간 표시, 돌리기는 회전 중심점을 점으로 표시.
- **입력 큐**: 애니메이션 중 추가 입력은 최대 2개까지 큐잉, 초과분 무시(연타 폭주 방지).
- 관찰 유도 문구가 변환마다 하단 토스트 스타일로 1회성 출현: "모양이 변했나요? 칸 수를 세어 보세요!"

### 2-3. 미션 (10개, 3단계)
| 단계 | 유형 | 문항 수 | 예시 |
|------|------|:---:|------|
| ① 식별 | 두 그림을 보여주고 "밀기/뒤집기/돌리기 중 무엇?" 3지선다 | 4 | ㄴ자가 좌우 반전된 그림 → `뒤집기` |
| ② 고스트 맞추기 | 목표 위치·방향의 반투명 고스트 제시 → 변환 버튼으로 일치시키기 (변환 1~2회) | 4 | "오른쪽으로 2칸 밀고 90° 돌리면 도착" |
| ③ 복합 | 고스트 맞추기 (변환 2~3회, 뒤집기+돌리기 조합 포함) | 2 | 뒤집기 없이는 절대 도달 불가한 배치 |

- 판정: 상태 `{x, y, flipX, flipY, rot}`의 **정규형 비교**(동일 배치를 만드는 서로 다른 변환 경로 모두 정답 인정 — 예: `상하뒤집기+180°돌리기 ≡ 좌우뒤집기`).
- 별점: 최소 변환 횟수 달성 ★3 / +1회 ★2 / 그 외 완료 ★1. 최소 횟수는 미션 데이터에 상수로 정의(런타임 탐색 불필요).
- 오답/초과 시 "처음으로" 후 재시도 무제한, 3회 초과 시 힌트("뒤집기가 필요해요") 노출.

### 2-4. 결과
- 별점 합계 + 미션별 별 목록.
- 배움 정리 카드: "밀기·뒤집기·돌리기 모두 **모양과 크기는 변하지 않아요. 위치·방향만 바뀌어요.**"
- 버튼: `다시 도전` / `자유 탐험으로` / 공유(현재 도형 배치).

## 3. 기술 설계 (코드 없음 — 규칙만)

### 3-1. 렌더링
- **SVG** 확정 (Canvas 대안 폐기): 모눈은 `<pattern>` 배경, 도형은 단일 `<g>` 안의 `<polygon>`, 변환은 CSS `transform` + `transition 0.4s`로 처리해 애니메이션 로직 최소화.
- 좌표계: 논리 단위 = 모눈 1칸. `viewBox="0 0 8 8"` 기준으로 도형 정점을 정수 좌표로 정의 → 리사이즈는 SVG가 알아서 처리(별도 리플로우 코드 불필요).

### 3-2. 상태 모델
```
state = { shapeId, x, y, flipX, flipY, rot }   // rot ∈ {0, 90, 180, 270}
```
- 변환 = 상태 갱신 → transform 문자열 재계산. DOM 좌표 직접 조작 금지.
- **정규형 규칙**: `flipX && flipY` 는 `rot+180`으로 흡수해 `flipY`를 항상 false로 정규화. 미션 판정은 정규형끼리 비교.
- 회전·뒤집기 기준점: 도형의 바운딩 박스 중심(모눈 반칸 단위 스냅). 회전 후 도형이 모눈 밖으로 나가면 안쪽으로 클램프.

### 3-3. 저장 · 공유
- `localStorage` 키: `shape-move:v1` → `{ missions: { m01: 3, ... }, freeState, settings }` — 개인정보 없음, 진도·별점만.
- 공유: `#share=` 해시에 `btoa(encodeURIComponent(JSON))` — payload `{ v: 1, state }` (자유 탐험의 현재 배치). 수신 측은 해당 배치로 자유 탐험 시작. `shareCurrentPage()`로 단축링크(공통 패턴, vives-share 규약 준수).
- 미션 진도는 공유 payload에 **포함하지 않음**(타인 진도 덮어쓰기 방지).

### 3-4. 의존성 · 성능
- 외부 CDN 0. 폰트는 공통 셸이 제공하는 것만.
- 오프라인·저사양에서 완전 동작(volcano의 maplibre 같은 fallback 자체가 불필요).

## 4. 디자인

- 공통 3종(`hero-theme.css` · `app-shell.css` · `theme.js`) + `init.js` / `app-shell.js` / `seo-injector.js` 로드 (개발 가이드 Phase 2 골격 그대로).
- 앱 팔레트: 밝은 학습 톤 — `:root`에 `--sm-grid`(모눈 선), `--sm-shape`(도형 채움), `--sm-ghost`(고스트, 40% 알파), `--sm-accent`(정답 강조) 정의. 다크모드에서 모눈 선/고스트 대비 체크 필수.
- 버튼: `.fd-btn` 계열. 방향키 4개는 십자 배치의 큰 아이콘 버튼.
- immersive 셸이므로 테마 토글은 자동 숨김(app-shell 규칙) — 시스템 테마 추종.

## 5. 스코프 제한 (Non-goals)

- **테셀레이션(무늬 만들기) 모드는 v1 제외** — 후속 확장으로 명시(상위 기획 §4-5). 공유 payload `v` 필드로 확장 여지만 확보.
- 도형 커스텀 제작, 다중 도형, 좌표평면(음수 좌표) 없음.
- 점수 랭킹·서버 상태 없음.

## 6. 제작·배포 절차

1. 스캐폴드:
   ```bash
   node scripts/scaffold-app.js --id shape-move --name "도형의 이동" --base immersive \
     --category edu --subcategory edu-sim --emoji 🔷 --desc "밀기·뒤집기·돌리기로 도형을 움직여 보세요"
   ```
2. `apps.json` 자동 등록 후 수동 보강: `badge: "시뮬레이션"` 추가, SEO 확정:
   - `seo.title`: `도형의 이동 — 밀기·뒤집기·돌리기 시뮬레이터`
   - `seo.description`: `모눈 위 도형을 직접 밀고 뒤집고 돌려 보세요. 초등 수학 4학년 평면도형의 이동을 애니메이션으로 체험하는 무료 학습 시뮬레이션.`
   - `seo.keywords`: `평면도형의 이동`, `밀기 뒤집기 돌리기`, `수학 4학년`, `도형 시뮬레이션`, `초등 수학`
3. 구현 → `npm run dev` 검증 → `npm run inject` → `npm run og` → `npm run sitemap` → 커밋.

## 7. 검수 체크리스트

- [ ] 4종 도형 모두에서 `좌우뒤집기` 결과와 `180° 돌리기` 결과가 시각적으로 구분되는가 (비대칭성 검증)
- [ ] 동일 배치에 도달하는 서로 다른 변환 경로가 모두 정답 처리되는가 (정규형 판정)
- [ ] 애니메이션 중 연타 시 큐 2개 초과분이 무시되고 상태가 어긋나지 않는가
- [ ] 회전/뒤집기 후 도형이 모눈 밖으로 나가지 않는가 (클램프)
- [ ] 모바일 세로 화면에서 캔버스와 조작 바가 겹치지 않고 터치 타깃 ≥ 44px인가
- [ ] `prefers-reduced-motion` 시 인트로 무한 애니메이션이 정지하는가
- [ ] 다크모드에서 모눈 선·고스트·도형 대비 확보, 포커스 링 정상
- [ ] 공유 링크 수신 시 배치 복원, 로컬 진도는 침범하지 않음
- [ ] inject/og/sitemap 산출물 정상 (개발 가이드 §7 공통 체크 포함)

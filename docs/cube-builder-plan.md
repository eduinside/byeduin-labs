# 큐브 만들기 (cube-builder) 계획

- 날짜: 2026-11-01
- 경로: `/apps/cube-builder/` (edu → edu-sim)
- 참고: 운영자가 Gemini Canvas로 만든 프로토타입 '입체 곱셈 큐브'(한 변 1~50 입력 → 3D 정육면체, A/B 비교, 단위 큐브 간격 넓히기, 자동 회전)

## 목표

숫자를 넣으면 단위 정육면체(쌓기나무)로 만든 3차원 모형이 바로 생기고, 두 모형을 나란히 놓고 개수를 비교한다.
초등 6학년 '직육면체의 부피'(단위 정육면체 개수 = 가로 × 세로 × 높이)와 큐브(세제곱) 감각을 눈으로 익힌다.

## 기능

| 기능 | 내용 |
|---|---|
| 모양 | 정육면체(한 변) / 직육면체(가로·세로·높이 각각). 프로토타입은 정육면체만 있었음 |
| 입력 | 숫자 칸 + −/+ + 슬라이더, 1~50. 자주 쓰는 수 바로 고르기 |
| 모드 | 하나 보기 / 둘 비교(A 파랑, B 빨강) |
| 식 카드 | `3 × 3 × 3 = 27`, 정육면체는 `3³` 표시 |
| 비교 문장 | 'A가 B보다 19개 더 많아요 (약 3.4배)', 같으면 '개수가 같아요' |
| 한 층씩 쌓기 | 바닥층부터 한 층씩 쌓이는 모습 재생 → 한 층의 개수 × 층수 |
| 틈 벌리기 | 단위 정육면체 사이를 벌려 속까지 꽉 찬 것을 확인 |
| 개수 가리기 | 수업에서 먼저 어림해 보게 결과 숫자를 가림, 누르면 보임 |
| 시점 | 끌어서 돌리기, 두 손가락·휠 확대, +/− 버튼, 처음 시점, 자동 회전 |
| 공유 | 상태를 URL 해시(`#s=cube&m=cmp&a=3,3,3&b=2,2,2`)에 기록 → 셸 공유 버튼이 그대로 공유 |

## 기술

- three.js(npm `three`)를 Astro `<script>`로 번들(이 페이지에서만 불러옴). 외부 CDN 없음.
- 그리기 비용: 기본 보기는 상자 하나에 '칸 무늬' 텍스처를 면마다 반복(repeat)해서 50³도 가볍게. 틈 벌리기 때만 InstancedMesh(최대 125,000개 × 2).
- SimKit 규약: 밝은 화면 고정(`theme="light"`), 토스트 위, `.sk-btn`, lucide 아이콘, 움직임 줄이기 존중(자동 회전·쌓기 애니메이션 끔).

## 하지 않는 것

- 미션·채점(필요하면 다음 단계에서 SimKit 미션으로).
- 겉넓이 계산.

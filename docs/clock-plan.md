### 잡아야 할 오개념
1. **시침이 두 숫자 사이일 때 큰 숫자로 읽기**: 3시 50분을 "4시 50분"으로. 가장 흔하다 → 전용 미션 + 시침 구간 색칠 보조 표시.
2. **분침이 가리키는 숫자를 그대로 분으로 읽기**: 분침이 3이면 "3분" → 바깥 고리 분 숫자(5, 10, …, 55) 보조 표시.
3. **시침·분침 혼동**: 길이·굵기·색을 확실히 다르게.
4. **걸린 시간에서 60을 100처럼**: 1시 50분 + 20분 = "1시 70분" → 분침이 12를 지나면 시침이 다음 칸으로 넘어가는 장면을 보여 줌.
5. **오전·오후, 낮 12시와 밤 12시**.

## 2. 단위 제한 (학년별 설정)

교사가 학년·진도에 맞춰 **시각을 다루는 가장 작은 단위**를 정한다. 이 값 하나가 앱 전체에 적용된다.

| 단위 | 권장 학년 | 끌기·버튼 맞춤 | 미션 문제 | 보조 표시 기본값 |
|---|---|---|---|---|
| 정각·30분 | 1학년 | 30분 | 몇 시, 몇 시 30분 | 시침 구간 색칠 켬, 분 숫자 끔 |
| 10분 | 2학년 처음 | 10분 | 10분 단위(3시 20분) | 분 숫자 켬 |
| 5분 | 2학년 | 5분 | 5분 단위(3시 25분) | 분 숫자 켬 |
| 1분 | 2학년 끝 | 1분 | 1분 단위(3시 27분) | 분 숫자 켬, 분 눈금 강조 |
| 1초 | 3학년 | 1초(초침 끌기) | 초 단위 + 시간 더하기·빼기 | 초침 켬 |

- **적용 범위**: 바늘을 놓았을 때 맞춤 간격, ± 버튼의 작은 단계, 키보드 ←/→ 한 번의 양, 무작위 문제 생성, 숫자 입력판(분 칸이 10분 단위면 0·10·20·…·50만 고르는 버튼으로 바뀜).
- **고르는 곳**: 인트로 화면과 설정(⚙) 시트의 큰 버튼 5개. 학년 이름을 같이 적는다("2학년 · 5분").
- **잠금**: 교사가 [이 단위로 학생 링크 만들기]를 누르면 `#share=`에 `{ v:1, unit, lock:true }`를 넣은 링크·QR이 나온다. 이 링크로 연 화면은 단위 버튼이 숨고 "선생님이 5분 단위로 정했어요"만 보인다. 잠금은 그 기기의 이번 방문 동안만(저장하지 않음) — 새로고침해도 주소에 해시가 남아 있으면 유지.
- **기록**: 미션 별은 단위마다 따로 저장한다(5분 단위로 다 깬 학생이 1분 단위로 바꾸면 새로 도전).

## 3. 화면 흐름

```
[인트로: 단위 고르기] → 모드 탭 [시계 놀이터] [미션] [큰 시계] → [결과]
```

### 3-1. 시계 놀이터(자유 탐험)
- 가운데 큰 아날로그 시계(SVG, 화면 짧은 변의 70% 안팎), 아래 디지털 표시와 읽기 문장 "3시 25분"(가리기 버튼), 🔊 읽어주기(`SimKit.speak`).
- **조작**
  - 분침 끌기: 시침이 톱니처럼 같이 돈다(분침 한 바퀴 = 시침 한 칸).
  - 시침 끌기: 분침도 함께 움직인다(실제 시계처럼).
  - 버튼: −1시간 / −단위 / +단위 / +1시간(단위가 1분이면 ±1분, ±5분도 추가).
  - 키보드 ←/→(단위만큼), ↑/↓(1시간).
  - "지금 시각"(단위에 맞춰 내림).
- **보조 표시**(켜고 끄기): 바깥 고리 분 숫자, 분 눈금 60개, 시침 구간 색칠(3과 4 사이 = "3시대"), 초침(1초 단위에서만), 하루 띠(0~24시 막대에 지금 위치, 오전 해·오후 달).

### 3-2. 미션
같은 미션 6개를 지금 단위로 문제를 만들어 낸다(SimKit `missions` 하나, 단위가 바뀌면 컨트롤러를 새로 만들고 그 단위의 기록을 불러옴).

| # | 미션 | 방식 |
|---|---|---|
| m1 | 시각 읽기 | 시계 → 보기 4개(정각·30분, 10분) 또는 숫자 입력판(5분·1분·1초) |
| m2 | 바늘 맞추기 | 시각 글 → 바늘을 끌어 맞추고 [다 했어요] |
| m3 | 헷갈리는 시침 | 분이 40분 이상(정각·30분 단위는 30분)이라 시침이 다음 숫자에 가까운 시계 → 읽기 (오개념 1) |
| m4 | 걸린 시간 | 시작·끝 시계 두 개 → "몇 시간 몇 분"(1초 단위는 "몇 분 몇 초") |
| m5 | 오전·오후 | 하루 일과 그림(아침밥·점심·잠) + 시계 → 오전/오후 고르기 |
| m6 | 시간 더하고 빼기 | "3시 40분에서 30분 뒤는?" → 바늘을 돌려 확인하며 답(1초 단위는 초 계산) |

- 미션 하나는 3문항. 단위 범위 안에서 무작위로 만든다(다시 풀 때마다 다름).
- 별: 3문항 중 첫 시도 정답 수(3개면 ★3). `keepBest: true`.
- 틀리면 정답을 바로 보이지 않고 힌트 한 단계(시침 구간 색칠, 분 숫자) 뒤 같은 문항 다시. 두 번째도 틀리면 바늘이 정답으로 돌아가는 애니메이션과 함께 정답을 보여 주고 다음 문항.
- 자동 이동 없음. 성공 문구 + [다음 미션] 버튼.

### 3-3. 큰 시계(교사용)
- 전자칠판용. 시계를 화면 가득, 읽기 문장은 기본으로 가림, [정답 보기].
- [무작위 시각](지금 단위 범위)으로 반 전체 문답.
- 공유: `#share=` `{ v:1, t, unit, show }` → 특정 시각의 시계를 링크로 보냄(학생 정보 없음). 2장의 잠금 링크와 같은 형식.

### 3-4. 결과
- 미션별 별, "시침은 지나온 숫자를 읽어요", "분침이 12를 지나면 한 시간이 지나요" 정리 카드. 다른 단위 도전 버튼.

## 4. 태블릿 조작

- 바늘 잡기 영역: 바늘 길이 전체에 폭 56px 이상의 투명 띠. 시침·분침 잡기 영역이 겹치는 가운데 부분은 손가락과 가까운 바늘 끝 쪽을 우선(분침이 더 길어 바깥쪽은 분침, 안쪽은 시침).
- 끄는 동안 바늘 끝 위쪽에 지금 시각 말풍선(손가락에 가리지 않게).
- 시계 영역 `touch-action: none`, 나머지는 스크롤 가능.
- 숫자 입력은 앱 안 입력판(시 1~12, 분은 단위에 맞는 버튼 또는 0~9 키패드). 화면 키보드를 띄우지 않는다.
- 레이아웃: 가로 화면은 시계 왼쪽·문제와 버튼 오른쪽, 세로 화면은 위아래. 높이 700px에서도 시계와 [다 했어요]가 한 화면에.

## 5. 기술 설계

### 상태
```
state = { t: 0..86399 (하루 중 초), unit: 'h30'|'m10'|'m5'|'m1'|'s1', lock: false,
          show: { minuteNums, ticks, hourZone, second, dayBar, reading } }
```
- 시침 각도 = `(t % 43200) / 120`도, 분침 = `(t % 3600) / 10`도, 초침 = `(t % 60) * 6`도.
- 분침 끌기: 직전 각도와의 차이를 −180~180도로 펴서 누적(12를 지나면 시간이 넘어감). 차이 × 10초를 `t`에 더한다.
- 시침 끌기: 차이 × 120초. 하루를 넘으면 0~86399로 감는다(오전·오후가 자연스럽게 바뀜).
- 초침 끌기(1초 단위): 차이 ÷ 6초.
- 끄는 중에는 맞춤 없이 부드럽게, 손을 떼면 단위 간격으로 맞춤(150ms).

### 그리기
- SVG `viewBox="0 0 400 400"`, 숫자 1~12, 분 눈금, 바깥 고리. 바늘은 `<g transform="rotate()">`.
- 시침·분침은 `role="slider"`, `aria-valuetext="3시 25분"`, 키보드 조작 가능.
- 색: 시침 짧고 굵은 주황, 분침 길고 가는 파랑, 초침 빨강. 길이·굵기 차이를 크게 해 색만으로 구분하지 않게.

### 저장·공유
- `SimKit.store('clock:v1', { defaults: { unit: 'm5', progress: { h30:{}, m10:{}, m5:{}, m1:{}, s1:{} }, show: {...} } })`
- 공유 받기: `t`는 0~86399 정수, `unit`은 다섯 값 중 하나, `lock`은 불리언으로 검사.

### 읽기 문장
- `formatKo(t, unit)`: "3시", "3시 30분", "3시 25분", "3시 25분 40초". 하루 띠가 켜져 있으면 "오후 3시 25분".
- "몇 시 몇 분 전"(4시 10분 전)은 놀이터에서 50분 이상일 때 작게 함께 표시. 미션 정답은 "몇 시 몇 분"으로 받는다.

## 8. 확인 목록

- [ ] 분침을 시계 방향으로 한 바퀴 끌면 정확히 1시간 늘고, 반대로 끌면 1시간 준다(12 지점 반복 통과 포함)
- [ ] 11시 55분 → 12시 5분으로 끌 때 오전·오후가 바르게 넘어간다
- [ ] 3시 50분에 시침이 4에 거의 닿지만 4를 넘지 않는다(각도 115도)
- [ ] 단위 다섯 가지 각각: 맞춤 간격, 버튼 단계, 입력판, 문제 범위(무작위 1,000회 node 시험)가 단위를 벗어나지 않는다
- [ ] 잠금 링크로 열면 단위 버튼이 없고, 해시 없는 주소로 다시 열면 풀린다
- [ ] 단위를 바꾸면 미션 기록이 단위별로 따로 보인다
- [ ] 태블릿(1280×800·1024×768 가로, 768×1024 세로) 터치로 바늘 잡기가 쉽고, 끄는 동안 화면이 움직이지 않는다
- [ ] 읽어주기 문장이 자연스럽다("3시 5분", "12시 30분")
- [ ] 라이트·다크, 375px·전자칠판 폭, 동작 줄이기, 키보드·화면 낭독기

### 발음 표기 기준

앱은 `pron`을 읽어 주기 화면에 "발음"으로 보여 주고, 채점은 `text`만 씁니다(띄어쓰기·문장부호 제외). `tags`는 규칙별 연습·오답 분석에 쓰입니다. 그래서 다음 기준으로 맞췄습니다.

1. **어절 안**에서는 표준 발음법을 모두 적용합니다(연음, 경음화, 비음화, 유음화, 격음화, ㅎ 탈락, 겹받침, ㄴ 첨가, 사잇소리).
2. **어절 사이**는 받아쓰기에서 끊어 불러 주는 것을 기준으로 해 연음·격음화·ㄴ 첨가·된소리를 적용하지 않습니다(예: 진심 어린[진심 어린], 영상 속 호랑이[영상 속 호랑이]). 기존 데이터 대부분이 이 방식이었습니다.
3. 다만 **관형사형 -(으)ㄹ 뒤 된소리(27항)** 는 띄어 쓴 말 사이에도 적용했습니다(할 수[할 쑤], 갈 곳을[갈 꼬슬], 않을 거라는[아늘 꺼라는]).
4. 2학년 1학기(`unit-2-1-*`) 파일은 발음에 문장부호를 넣지 않고, 나머지 파일은 표기의 문장부호를 발음에도 그대로 둡니다(기존 관례 유지).
5. 태그는 앱이 아는 6개(연음화·경음화·격음화·비음화·겹받침_단순화·받침없음/규칙없음) 안에서만 골랐습니다. **ㄴ 첨가·유음화·ㅎ 탈락·받침 대표음만 일어나는 문항**(그림일기, 분류해서, 응 좋아, 노랑 꽃 등 8건)은 맞는 태그가 없어 '받침없음/규칙없음'으로 두었습니다. 앱에 태그를 늘릴지는 따로 정해 주세요.

## 6. 점검 방법과 재점검 결과

점검 스크립트로 31개 파일 997문항을 다음 기준으로 확인했습니다.

1. 표기와 발음의 음절 수·어절 수 비교 → 다른 것 0건
2. 발음 안의 한글·문장부호가 아닌 글자 → 0건
3. 규칙 태그가 있는데 발음이 표기와 같은 것 → 0건
4. '받침없음/규칙없음' 태그인데 발음이 표기와 다른 것 → 8건(위 기준 5의 ㄴ 첨가·유음화·ㅎ 탈락·대표음 문항, 의도한 것)
5. 같은 파일 안 중복 id → 0건 (단원 간 id 중복은 앱이 "단원 코드 + id"로 구분하므로 문제없음)
6. `char_len`과 실제 한글 글자 수 → 다른 것 0건
7. 발음 문장부호가 파일 관례와 다른 것 → 0건
8. 어절·음절을 맞춘 모음 바뀜, ㅎ 탈락 미반영, 연음 누락, 대표음 미적용, 관형사형 -ㄹ 뒤 된소리 누락 → 0건(남은 2건 "쳤→첟", "쳐→처"는 표준 발음 '져·쳐→[저·처]'라 맞음)
9. 문장 문항 끝 문장부호 없음 → 83건(위 "고치지 않고 남긴 것" 참고)

스크립트가 잡지 못하는 유형(뜻이 어색한 문장, 빠진 태그 등)은 사람이 하나하나 본 것이 아니므로 남아 있을 수 있습니다.

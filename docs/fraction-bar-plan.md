## 1. 개요

| 항목 | 값 |
|------|-----|
| 앱 ID | `fraction-bar` (`/apps/fraction-bar/`) |
| 이름 · 이모지 | 분수 막대 · 🍫 |
| 셸 | `column` / `medium`(720) — 조작 도구 + 미션의 세로 흐름. immersive 불필요(뷰포트 소유할 이유 없음, 저학년에게 스크롤 흐름이 더 안전) |
| 카테고리 | `edu` / `edu-sim` · 배지 `시뮬레이션` |
| 한 줄 | 초콜릿 막대와 피자를 직접 자르고 칠하며 분수의 크기를 눈으로 비교 |
| 교과 | 수학 3학년 「분수」(등분·단위분수·크기 비교) · 4학년 분수 연계 |
| 대상 기기 | 저학년 태블릿 우선 — 큰 터치 타깃, 최소 텍스트 |

### 학습 목표 (성취기준 수준)
1. 전체를 **똑같이 나누는 것(등분)**이 분수의 전제임을 안다.
2. 단위분수(1/n)는 **분모가 클수록 작다**는 것을 겹쳐 보며 발견한다.
3. m/n을 "1/n이 m개"로 이해하고, 크기가 같은 분수(1/2 = 2/4)가 존재함을 확인한다.

### 오개념 교정 포인트 (이 앱의 핵심 가치)
- **"분모가 크면 큰 분수"** → 1/3과 1/8 막대를 겹쳐서 즉시 반증. 최우선 타깃 오개념.
- **"아무렇게나 나눠도 분수"** → 부등분 예시를 보여주고 "조각 크기가 다르면 분수가 아니에요" 판정 체험(미션 ①).
- **"1/2과 2/4는 다른 수"** → 두 막대를 겹쳐 길이가 정확히 일치함을 확인.

## 2. 화면 흐름 (volcano 골격의 column 적용)

```
[인트로 카드] → [자유 탐험: 공작소] → [미션 8개] → [결과 정리]
```

### 2-1. 인트로
- 미션 카드: "초콜릿을 **똑같이** 나누면 분수가 보여요!" + `시작하기`.

### 2-2. 자유 탐험 — 분수 공작소
막대(초콜릿)와 피자(원형) 두 표현을 탭으로 전환. 조작은 동일 3단계:

1. **자르기**: 등분 수 선택 `2~12` — 스테퍼 버튼(－/＋) + 프리셋 칩(2·3·4·6·8·12). 자르는 순간 칼선 애니메이션(0.3s).
2. **칠하기**: 조각을 탭하면 채움/해제 토글. 채운 수에 따라 상단에 분수 표기가 실시간 갱신 — `3/8` + 읽기 "8분의 3".
3. **겹쳐 보기(비교)**: `비교 모드` 토글 시 막대가 2개(A/B)로 늘어나 위아래로 나란히 정렬. `겹치기` 버튼으로 B가 A 위로 슬라이드(0.4s, 반투명)되어 길이 차이가 드러남. 피자 모드에서는 부채꼴이 같은 중심으로 오버레이.

- 항상 표시되는 것: "전체 1"의 기준선(막대 전체 테두리). 분수는 전체에 대한 상대량임을 시각적으로 고정.
- 조각 수·채움 상태가 바뀔 때마다 분수 표기와 읽기가 함께 갱신 — 기호·언어·시각 표현의 3중 연결.

### 2-3. 미션 (8개, 3단계)
| 단계 | 유형 | 문항 수 | 예시 |
|------|------|:---:|------|
| ① 등분 판별 | 나눠진 막대 그림 → "분수로 나타낼 수 있을까요?" O/X | 2 | 부등분 막대 → X ("조각 크기가 달라요") |
| ② 만들기 | 지시된 분수를 자르기+칠하기로 제작 | 3 | "3/4을 만들어 보세요" · "8분의 5를 만들어 보세요"(읽기→기호 변환) |
| ③ 비교 | 두 분수 중 큰 것 예측 → 겹쳐서 확인 | 3 | 1/3 vs 1/4 · 2/5 vs 3/5 · 1/2 vs 2/4(같음! — 3지선다에 "같아요" 포함) |

- ③은 반드시 **예측 먼저**(버튼 선택) → 겹치기 애니메이션으로 확인 → 정오 피드백. 예측 없이 확인 불가(volcano의 예측→확인 원칙).
- 별점: 첫 시도 정답 ★3 / 2회 ★2 / 그 외 ★1.

### 2-4. 결과
- 별점 합계 + 배움 정리 카드: "분수는 **똑같이 나눈** 것 중 몇 개인지를 나타내요. **분모가 클수록 한 조각은 작아져요.**"
- `다시 도전` / `공작소로` / 공유(내가 만든 분수 배치).

## 3. 기술 설계

### 3-1. 렌더링
- **SVG**: 막대는 `<rect>` 나열, 피자는 `<path>` 부채꼴. shape-move에서 확립한 SVG+CSS transition 패턴 재사용.
- 겹치기 비교는 두 `<g>` 레이어의 translate 트랜지션 + 상단 레이어 60% 알파.
- 등분 수 변경 시 조각을 전부 재생성(diff 불필요 — 최대 12개라 비용 없음). 채움 상태는 가능한 만큼 보존(등분 수가 줄면 잘라냄).

### 3-2. 상태 모델
```
state = {
  view: 'bar' | 'pizza',
  compare: false,
  a: { denom, filled: [i, ...] },
  b: { denom, filled: [...] }        // compare 모드에서만 사용
}
```
- 분수 값 = `filled.length / denom`. 파생값이므로 저장하지 않음.
- 미션 판정: `filled.length`와 `denom`만 비교(어느 조각을 칠했는지는 무관).

### 3-3. 저장 · 공유
- `localStorage` 키: `fraction-bar:v1` → `{ missions: {...}, lastState }`.
- 공유: `#share=` payload `{ v: 1, state }` — "내가 만든 분수" 배치 공유. `shareCurrentPage()` 단축링크. 미션 진도 미포함.

### 3-4. 의존성
- 외부 CDN 0. 오프라인 완전 동작.

## 4. 디자인

- 공통 3종 + 표준 스크립트 로드. `column`/`medium` 셸이라 `.app-header`(배지 `◆ EDU` + 제목 + 설명) 표준 사용.
- 팔레트: 초콜릿 톤 `--fb-bar`(채움), `--fb-empty`(빈 조각), `--fb-cut`(칼선), 비교용 `--fb-b`(B 막대, A와 명확히 다른 색상 + 패턴 병용 — 색약 대비).
- 저학년 배려: 본문 폰트 크기 한 단계 크게, 조각 터치 타깃은 등분 12일 때도 ≥ 44px 확보(막대 높이로 보상), 텍스트 최소화·아이콘 우선.
- 다크모드: 빈 조각과 배경의 경계 대비 필수 확인.

## 5. 스코프 제한 (Non-goals)

- 분수 **연산**(덧셈·뺄셈·통분) 없음 — 크기·등분 개념에 집중. 연산은 별도 앱 후보.
- 대분수·가분수 없음(전체 1 초과 표현 제외). 수직선 표현 없음.
- 3개 이상 동시 비교 없음(A/B 2개 고정).

## 6. 제작·배포 절차

1. 스캐폴드:
   ```bash
   node scripts/scaffold-app.js --id fraction-bar --name "분수 막대" --base column --width medium \
     --category edu --subcategory edu-sim --emoji 🍫 --desc "막대와 피자를 자르고 칠하며 분수 크기 비교"
   ```
2. `apps.json` 수동 보강: `badge: "시뮬레이션"`, SEO 확정:
   - `seo.title`: `분수 막대 — 자르고 칠하는 분수 크기 비교`
   - `seo.description`: `초콜릿 막대와 피자를 직접 등분하고 칠해 보세요. 초등 수학 3학년 분수 개념과 크기 비교를 눈으로 익히는 무료 학습 시뮬레이션.`
   - `seo.keywords`: `분수`, `분수 크기 비교`, `단위분수`, `수학 3학년`, `등분`, `초등 수학`
3. 구현 → `npm run dev` → `npm run inject` → `npm run og` → `npm run sitemap` → 커밋.

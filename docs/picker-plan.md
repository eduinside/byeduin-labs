# 뽑기·모둠(picker) 계획

## 2. 쓰는 장면

- 발표자 한 명 뽑기, 오늘 안 뽑힌 사람 중에서 뽑기
- 발표·실험 순서 정하기
- 4명씩 모둠 나누기. 같이 두면 안 되는 학생은 떨어뜨리고, 지난번 모둠과 겹치지 않게
- 명단 없이 "1~28번 중 하나"만 뽑기

## 3. 화면 구성

### 3-1. 명단(학급) 화면
- 학급 카드 목록(여러 학급 관리). `＋ 새 학급`, 이름 바꾸기·복제·삭제.
- 명단 넣는 방법 세 가지:
  1. **붙여넣기**: 한 줄에 한 명. `이름`, `이름 남/여`(자리 배치와 같은 형식, 같은 파서 함수).
  2. **번호만**: 인원 수만 넣으면 `1번`~`N번`. 이름을 기기에 남기고 싶지 않을 때.
  3. **자리 배치에서 가져오기**: `vives-seating-v1`을 읽기만 해서 학급을 고르면 이름·성별·떨어뜨릴 쌍을 복사해 온다. 자리 배치 데이터는 건드리지 않는다. 자리 배치 학급이 없으면 버튼을 숨긴다.
- **오늘 결석**: 이름을 눌러 표시. 표시한 날짜를 함께 저장해 다음 날 자동으로 풀린다.
- 안내 문구: "명단은 이 기기의 브라우저에만 저장돼요."

### 3-2. 도구 탭 (학급 안)

| 탭 | 내용 |
|---|---|
| 🎯 뽑기 | 1명 또는 N명. 방식: **공평하게**(모두 한 번씩 뽑힐 때까지 중복 없음, 남은 인원 표시, 다 뽑히면 새 바퀴) / **매번 새로**(중복 허용). 결석 제외. 오늘 뽑힌 기록, **방금 뽑기 취소**(결석생이 뽑혔을 때 등) |
| 🔢 순서 | 전체를 무작위 순서로 나열. 큰 번호 카드, 지나간 사람 체크, 한 명씩 넘기기 |
| 👥 모둠 | 모둠 수 또는 모둠당 인원. 조건: 떨어뜨릴 쌍, 성별 섞기, 지난 모둠과 겹침 줄이기, 특정 학생 고정. 모둠장 무작위 표시(선택). 결과 카드에서 끌어 놓아 맞바꾸기, 다시 섞기, 되돌리기, A4 인쇄 |

### 3-3. 무대(전체화면)
- 전자칠판용. 뽑힌 이름을 화면 가득, 순서·모둠 결과도 큰 글씨.
- 뽑기 연출 3가지(설정에서 고름): **슬롯**(이름이 빠르게 바뀌다 멈춤, 기본), **카드**(뒤집힌 카드 N장 중 학생이 하나 고름), **룰렛**(원판, 40명 이하).
- 연출 길이 짧게/보통, 효과음 켜기·끄기(`SimKit.sound`의 소리 재사용 또는 같은 Web Audio 코드). `prefers-reduced-motion`이면 연출 없이 바로 표시.
- 키보드: Space/Enter 다시 뽑기, Esc 무대 닫기, ←/→ 순서 넘기기.

## 4. 알고리즘

- **난수**: `crypto.getRandomValues` 기반 정수 난수(나머지 편향 제거)로 Fisher–Yates 섞기. 공정성 시비를 막기 위해 `Math.random`은 쓰지 않는다.
- **공평하게 뽑기**: 학급마다 `bag`(아직 안 뽑힌 id 목록)을 저장. 결석생은 이번 뽑기에서만 빼고 bag에는 남긴다. 명단이 바뀌면 bag을 새 명단과 맞춘다(빠진 학생 제거, 새 학생 추가).
- **모둠 나누기**: 자리 배치의 랜덤 배치처럼 "여러 번 섞어 벌점이 가장 낮은 것"을 고른다.
  - 모둠 크기 차이는 최대 1. "모둠당 N명"으로 정하면 남는 학생 처리를 고른다: **모둠에 더하기**(기본, 26명 4명씩 → 6모둠 5·5·4·4·4·4) / **작은 모둠 만들기**(7모둠 4·4·4·4·4·3·3).
  - 벌점: 떨어뜨릴 쌍이 같은 모둠(큰 벌점) > 지난 모둠에서 같이 있던 쌍 수 > 모둠별 성별 편차.
  - 고정 학생은 먼저 배치하고 나머지만 섞는다. 시도 횟수 300회 안팎(학생 40명 기준 수십 ms 확인).
  - 조건을 다 지킬 수 없으면(예: 떨어뜨릴 쌍이 너무 많음) 결과는 보여 주되 "지키지 못한 조건 2개"를 표시한다.
- **지난 모둠**: 모둠을 확정(`이대로 쓰기`)할 때만 기록. 최근 3회까지 보관.

## 5. 저장

- 키 `vives-picker-v1`: `{ v:1, classes:[{ id, name, students:[{id,name,gender}], pairs:[[a,b]], absent:{date, ids}, bag:[ids], history:[{t, ids}], groupsHistory:[[[ids]…]] , settings }] }`
- 읽을 때 형식 검사(이름 20자, 학생 200명, 기록 100건 상한). 손상되면 빈 상태로 시작하고 안내.
- JSON 내보내기·불러오기(기기 옮기기용). 서버 저장 없음.

## 6. 화면·접근성

- 공용 `VUI`(토스트·모달·저장), 디자인 토큰, 다크 모드.
- 무대 글자 크기는 화면 높이에 맞춰 자동(긴 이름은 줄여 맞춤).
- 결과는 `aria-live="polite"`로 읽어 준다(연출이 끝난 뒤 한 번).
- 모둠 카드 맞바꾸기는 Pointer Events 끌기 + "학생 누르고 → 옮길 모둠 누르기" 2탭 대체 조작.

## 7. 하지 않는 것

- 공유 링크·QR·기기 간 동기화(학생 이름 보호)
- 칭찬 점수·스티커 같은 학급 관리 기능
- 자리 배치 데이터에 쓰기(가져오기만)
- 공용 명단 모듈(`public/common/roster.js`)은 이번에 만들지 않는다. 뽑기·모둠이 자리 배치 형식을 읽기만 하고, 세 번째 앱이 명단을 쓰게 되면 그때 뽑는다.

## 8. 작업 순서

1. 스캐폴드:
   ```bash
   node scripts/scaffold-app.cjs --id picker --name "뽑기·모둠" --emoji 🎲 --lucide dices --desc "발표자 뽑기·순서 정하기·모둠 나누기" --category edu --subcategory edu-work --base column --width wide --print
   ```
2. `apps.json`: `badge: "업무경감"`, SEO
   - title: `뽑기·모둠 — 발표자 랜덤 뽑기와 모둠 나누기`
   - description: `학급 명단으로 발표자를 공평하게 뽑고, 발표 순서를 정하고, 조건을 지켜 모둠을 나눠요. 전자칠판에 크게 띄우고 A4로 인쇄합니다. 명단은 이 기기 브라우저에만 저장돼요.`
   - keywords: `발표자 뽑기`, `랜덤 뽑기`, `모둠 나누기`, `조 편성`, `순서 정하기`, `이름 룰렛`
3. 명단 화면(붙여넣기·번호만·자리 배치 가져오기·결석)
4. 뽑기 탭 + 무대 + 연출 3종
5. 순서 탭
6. 모둠 탭(알고리즘, 끌어 놓기, 인쇄)
7. 확인 → 문서 갱신 → 커밋

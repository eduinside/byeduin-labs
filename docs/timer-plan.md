## 2. 화면 구성

```
[상단]  지금 시각 · "지금 3교시 · 쉬는 시간까지 12분"(사용 중 시정이 있을 때)

```

- 첫 탭은 **카운트다운**(수업 중 가장 많이 씀). 마지막에 연 탭을 기억한다.
- 기존 "알람" 화면은 그대로 두고 탭 하나로 옮긴다(저장 형식 유지).
- 하단 고정 바는 토스트와 겹치지 않게 `--vui-toast-bottom`을 쓴다(이미 적용된 방식).

## 3. 기능별 상세

### F1. 카운트다운 (전체화면)

- **시작**: 빠른 버튼 1·3·5·10분 + 직접 입력(분·초). 숫자 키패드 모양으로 전자칠판 터치에 맞게(버튼 64px 이상).
- **표시**: 아주 큰 `MM:SS`(화면 짧은 변의 35%), 아래로 줄어드는 막대 또는 원형 링(설정에서 고름).
  - 남은 시간 색: 50% 이상 초록 → 20% 이상 노랑 → 그 아래 빨강.
  - 마지막 10초는 숫자가 커지고 초마다 짧은 소리(설정에서 끔).
- **조작**: 일시정지/이어서, +1분, 다시 시작, 끝내기. 키보드: Space 일시정지, ↑ +1분, Esc 전체화면 나가기.
- **끝날 때**: 알람과 같은 소리(고를 수 있음) + 화면 깜빡임 3번 + "시간 끝!" 큰 글자. 자동 정지는 60초(알람과 같음).
- **정확도**: 끝나는 시각(`endAt = Date.now() + ms`)을 저장하고 매 틱마다 `endAt - now`로 계산(탭이 느려져도 어긋나지 않음). 새로고침해도 `endAt`이 남아 있으면 이어서 보여 준다.
- **전체화면**: `requestFullscreen()`(지원 안 하는 iOS Safari는 화면 꽉 채운 오버레이로 대체). 전체화면 중에는 공용 상단 버튼을 숨긴다.
- **알람과의 관계**: 카운트다운 중에 시정·알람이 울리면 알람이 이기고, 카운트다운은 멈추지 않고 뒤에서 계속 간다.

### F2. 자주 쓰는 타이머

- 데이터: `timer_presets: [{ id, name, sec, sound, color, order }]`(최대 20개). 처음에는 예시 4개(생각하기 3분·짝 활동 5분·독서 15분·청소 10분).
- 카운트다운 탭 위쪽에 버튼 줄로 표시 → 누르면 바로 시작(전체화면 설정이 켜져 있으면 바로 전체화면).
- 편집: 길게 누르기/연필 아이콘 → 이름·시간·소리·색. 순서 바꾸기는 위/아래 버튼(끌기는 터치에서 불편).
- 지우기는 되돌리기 토스트(공용 `VUI.toast({action})`).

### F3. 시정 만들기·저장·불러오기

- 데이터:
  ```js
  timetables: [{
    id, name: '평일 시정',
    days: [1,2,3,4,5],                       // 이 시정을 쓰는 요일
    periods: [{ label:'1교시', start:'09:00', end:'09:40', kind:'class' },
              { label:'쉬는 시간', start:'09:40', end:'09:50', kind:'break' }, …],
    chime: { atStart:true, atEnd:true, before:1, sound:'chime' },   // 수업 1분 전 예비 종 등
    updatedAt
  }]
  timetable_active: 'id'                     // 사용 중 시정(없으면 시정 알람 꺼짐)
  ```
  `kind`: class(수업)·break(쉬는 시간)·lunch(점심)·morning(아침 활동)·after(방과 후)·etc.
- **편집 화면**: 표(교시 이름 | 시작 | 끝 | 종류) + 행 추가/삭제. 도우미 버튼:
  - "기본 틀 불러오기": 초등 40분(9:00 시작, 쉬는 시간 10분, 점심 12:10~13:00), 중학교 45분.
  - "모든 수업 시간 일괄 변경"(예: 단축 수업 35분) — 시작 시각과 쉬는 시간 길이를 지키며 다시 계산.
  - 겹침·순서 오류는 빨간 줄로 표시하고 저장을 막는다.
- **여러 개 저장**: 평일·수요일 단축·시험 기간·방학식 날처럼 이름 붙여 저장. 목록에서 "사용하기"로 바꾼다. 요일이 겹치면 사용 중 시정 하나만 적용.
- **알람으로 쓰는 방식**: 시정은 기존 `alarms` 목록에 **복사하지 않는다**. 틱마다 사용 중 시정에서 "지금 울릴 종"을 계산해 같은 발동 함수(`triggerAlarm`)로 보낸다(시정을 바꾸면 알람이 바로 따라 바뀜). 알람 목록 화면에는 "시정 알람 18개(평일 시정)"로 묶어 한 줄만 보여 준다.
- **상단 안내**: "지금 3교시 · 쉬는 시간까지 12분"·"점심시간 · 5교시까지 8분"·"방과 후". 이것이 시정 기능의 핵심 효용.
- **불러오기·내보내기**: 기존 "파일로 저장/불러오기"에 시정·프리셋을 포함(형식 `{ v:2, alarms, timetables, presets, … }`, v1 파일도 읽음). 동료 교사에게 시정만 보내는 **공유 링크**(`#share=`, VUI.share)도 넣는다 — 같은 학교 선생님이 그대로 가져가기 쉬움.

### F4. AI 시정 인식 (사진·이미지 → 시정)

- **흐름**: [사진 찍기/이미지 고르기/붙여넣기] → 브라우저에서 긴 변 1280px·JPEG 품질 0.75로 줄임(대략 150~350KB) → `/api/timer-vision` → 결과를 **F3 편집 표에 채워서 보여 줌** → 교사가 확인·수정 → 저장. AI 결과를 바로 저장하지 않는다(시각 오인식은 바로 수업 종 오류로 이어짐).
- **서버** `functions/api/timer-vision.js` (신규):
  - `_guard.js`로 같은 출처만, 한도 `LIMITS['timer-vision'] = { perMin: 6, perDay: 40, siteDay: 400 }`(이미지 요청은 비싸므로 낮게).
  - 본문 상한 600KB, `data:image/jpeg|png|webp;base64,` 접두사만 허용.
  - 모델 호출: `_ai.js`에 이미지 입력을 받는 `generateContent({ …, images:[dataUrl] })` 확장을 추가한다.
    - Timely(OpenAI 호환): `content: [{type:'text'}, {type:'image_url', image_url:{url:dataUrl}}]`, 모델은 byeduin 기본 `openai/gpt-5.6-luna`(2026-10-06 실측: 인쇄형 시정표 10행 정확 인식, 약 6초).
    - Gemini 직접 폴백: `parts: [{ inline_data:{ mime_type, data } }, { text }]`.
    - 다른 앱이 쓰는 텍스트 경로는 바꾸지 않는다(이미지 인자가 있을 때만 분기).
  - 출력은 JSON만: `{ name, periods:[{label,start,end,kind}], days?, confidence, notes }`. 서버에서 다시 검사(HH:MM 형식, 시작<끝, 최대 20행, 라벨 20자) 후 돌려준다.
  - **이미지는 저장하지 않는다**(로그에도 남기지 않음).
- **화면 안내**: "학교 이름·선생님 이름이 보이면 잘라서 올려 주세요. 사진은 AI 분석에만 쓰고 저장하지 않아요(외부 AI 서비스로 전송)." 인식 결과의 확실하지 않은 칸은 노란색으로 표시(`confidence`·`notes`).
- **CPU 10ms 제약**: 본문 JSON 파싱이 이미지 크기에 비례한다. 클라이언트에서 크기를 줄여 보내고(상한 600KB), 서버는 파싱 뒤 문자열을 그대로 넘겨 재인코딩하지 않는다. 실측해서 넘으면 이미지 상한을 낮춘다(시정표는 글자 위주라 1024px로도 충분할 가능성이 큼).
- **실패 시**: "표를 찾지 못했어요. 더 밝게, 표만 보이게 다시 찍어 주세요" + 직접 입력으로 이어 가기.

### F5. 쉬는 시간 음악 추천 (유튜브 임베드)

- **추천 기준**: 사용 중 시정의 **지금/다음 쉬는 시간 길이**(예: 10분)와 상황(쉬는 시간·점심·아침 활동·청소·집중 활동·정리)을 함께 본다. 남은 시간보다 짧은 곡만 고른다.
- **곡 목록**: 운영자가 고른 목록 `public/apps/timer/music.json`(초기 40~60곡). 항목 `{ id:'YouTube ID', title, mood:['break','focus','calm','clean'], grade:'all|low|high', sec }`.
  - 길이(`sec`)는 기존 `/api/yt-duration`(7일 엣지 캐시)으로 채우고 json에 기록해 두므로 평소에는 서버 호출이 없다.
  - **어린이에게 맞는지·임베드 허용 여부를 운영자가 확인한 곡만** 넣는다(유튜브 추천 알고리즘을 그대로 띄우지 않음).
  - 교사가 자기 링크를 추가하는 "내 음악" 목록(`timer_music_custom`, 최대 30개)도 둔다. 유튜브 주소만 받고 ID만 저장.
- **재생**: `https://www.youtube-nocookie.com/embed/<id>?autoplay=1&rel=0&modestbranding=1`, 화면 아래 작은 플레이어(접기 가능). 다음 수업 시작 30초 전에 소리를 줄이고 시작 종과 함께 멈춤(설정).
  - 자동 재생은 브라우저가 막을 수 있어 첫 재생은 교사가 누르게 한다.
  - 광고·추천 영상이 끝에 뜰 수 있다는 점을 안내(유튜브 정책상 완전히 막을 수 없음).
- **AI 추천(선택, 후순위)**: 곡을 AI가 고르게 하지 않는다 — 학교 화면에 낯선 영상이 뜨는 위험이 크다. AI는 쓰지 않고 위 목록 안에서 규칙으로 고른다.
- 학교망에서 유튜브가 막혀 있으면 "유튜브에 연결할 수 없어요" 안내만 하고 나머지 기능은 그대로 동작.

### F6. 계정(코드)에 저장 — 기존 VivesSync 확장

- 이미 `mountDocSync({ apiUrl:'/api/timer', keys:['alarms','alarm_logs'] })`가 있다. **keys만 늘린다**:
  `['alarms','alarm_logs','timetables','timetable_active','timer_presets','timer_music_custom','timer_settings']`.
- 서버(`functions/api/timer.js`, D1 `timer_docs`)·코드 체계(공용 `vives:code`)는 그대로 → 마이그레이션 없음.
- 용량: 코드당 256KB 상한. 시정 5개·프리셋 20개·음악 30개를 합쳐도 약 20KB라 충분. `alarm_logs`가 가장 크므로 동기화 대상에서는 최근 50건만 보낸다(로컬은 200건 유지).
- 이미지(F4)는 동기화하지 않는다.

### F7. 화면 꺼짐 방지 (켜고 끄기)

- 하단 바에 스위치 "화면 켜 두기". 기본값: **시정 사용 중이거나 카운트다운 중이면 켬**, 아니면 끔(지금은 항상 켜져 있어 노트북 배터리를 쓴다).
- 상태 표시: 켜짐(●초록)·지원 안 함(회색, 이유 툴팁 대신 문구) · 브라우저가 해제했을 때(탭 전환 등) 돌아오면 다시 요청.
- 설정은 `timer_settings.wakeLock`('auto'|'on'|'off')에 저장.

### F8. 가림 화면 타이머 (운영자 정의 2026-10-06)

- **뜻**: 정한 시간 동안 화면 전체를 **검은 창으로 가려 두었다가, 시간이 지나면 검은 창이 저절로 걷히는** 타이머. 모니터 전원을 끄는 기능이 아니다.
  - 쓰임: 시험·쪽지 시험 중 칠판 화면 가리기, 쉬는 시간 동안 화면 가리기(눈부심·주의 분산 방지), 답 공개 전 잠시 가리기.
- **시작**: 하단 바 "가림 화면" → 시간 고르기(1·3·5·10·15분, 직접 입력, "다음 종까지" — 사용 중 시정이 있을 때). 자주 쓰는 타이머(F2)에도 "가림 화면으로 시작" 옵션.
- **가린 동안**: 완전 검정 바탕. 설정에 따라 화면 구석에 아주 흐린 남은 시간(기본: 표시 안 함 / 흐린 작은 숫자 / 가운데 큰 숫자) 중 하나. 화면 꺼짐 방지(wake lock)를 켜 두어 가림 도중 모니터가 꺼지지 않게 한다. 전체화면을 시도한다.
- **끝날 때**: 검은 창이 0.6초 동안 서서히 걷히고(움직임 줄이기면 바로), 짧은 알림음(설정에서 끔). 시정·알람 종이 먼저 울리면 그때 바로 걷는다(설정, 기본 켬).
- **도중에 걷기**: 화면을 두 번 누르거나 Esc → "가림 화면을 끝낼까요?" 확인(실수로 학생이 건드리는 것 방지). 키보드 Space는 무시.
- **정확도·복구**: 카운트다운과 같이 끝나는 시각(`endAt`)으로 계산, 새로고침해도 남은 시간 동안 다시 가린다(`timer_blank`).

## 7. 확인 방법

- 카운트다운: 탭을 숨겼다 돌아와도 남은 시간이 맞는지, 새로고침 후 이어지는지, 120Hz 화면, 마지막 10초 소리.
- 시정: 기본 틀 → 단축 수업 일괄 변경 → 겹침 오류 표시 → 사용하기 → 시각을 바꿔(개발용 시계 이동) 시작·끝·예비 종이 한 번씩만 울리는지.
- AI: 실제 학교 시정표 이미지(인쇄물 사진·한글 파일 캡처·손글씨) 각 2장 이상, 오인식 칸 표시, 한도 초과 안내.
- 음악: 학교망 차단 시 안내, 다음 수업 직전 자동 멈춤.
- 꺼짐 방지·가림 화면: Chrome/Edge(지원), Safari(대체 동작), 전자칠판 브라우저. 가림 화면이 정한 시간 뒤 걷히는지, 새로고침 뒤 남은 시간만큼 다시 가리는지.
- 공통: 375×740·844×390·1280×720·1920×1080 겹침 0, 빌드·스모크, 동기화(두 기기에서 시정 이어쓰기).

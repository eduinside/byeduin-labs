### 핵심 아이디어
**같은 자료를 여러 그래프로 즉시 바꿔 본다.** 종류를 바꾸면 막대가 원 조각으로, 점이 선으로 바뀌는 전환 애니메이션을 보여 "그래프마다 잘 보이는 것이 다르다"를 체감하게 한다.

### 잡아야 할 오개념
1. **눈금 한 칸 = 1**이라고 생각(한 칸이 2·5·10일 때 잘못 읽음)
2. **세로축이 0에서 시작하지 않는 막대그래프**로 차이를 부풀려 읽음 → 물결선 의미
3. **꺾은선그래프의 선 위 중간값**의 의미(측정하지 않은 시각의 값은 짐작값)
4. **띠·원그래프 백분율 합**이 반올림 때문에 100이 안 되는 경우
5. 그림그래프에서 **큰 그림과 작은 그림의 단위** 혼동

## 2. 화면 구성

### 2-1. 조사하기 (교실 투표 집계)
- 항목 버튼을 크게(최대 8개). 누를 때마다 +1, 옆에 바를 정(正) 또는 `////` 표시. 되돌리기.
- 전자칠판에서 손든 학생 수를 세거나 학생이 나와 직접 누름.
- [표로 정리하기] → 2-2로 자료를 넘김.

### 2-2. 그래프 작업대
- **표 편집**: 제목, 항목 이름(최대 12개), 값(0~9999 정수, 꺾은선·평균은 소수 첫째 자리 허용), 단위(명·회·°C 등). 행 추가·삭제·순서 바꾸기. 엑셀·구글 시트에서 복사한 두 열 붙여넣기.
- **종류 탭**: ○그래프 · 그림그래프 · 막대(세로/가로) · 꺾은선 · 띠 · 원. 학년 표시(1~2 / 3~4 / 5~6)를 탭에 작게 달아 교사가 고르기 쉽게.
- **종류별 설정**
  | 종류 | 설정 |
  |---|---|
  | ○그래프 | 기호 ○·×·/, 가로·세로 |
  | 그림그래프 | 단위 그림(이모지 선택), 큰 그림 = 10 또는 5, 작은 그림 = 1 |
  | 막대 | 눈금 한 칸 크기(자동/1/2/5/10/…), 가로·세로, 값 표시 |
  | 꺾은선 | 물결선(세로축 아래 생략) 켜기, 시작값, 점 값 표시 |
  | 띠·원 | 백분율 반올림 자리, 합계 맞추기(아래 4장) |
- **직접 그리기**(끄기 기본): 자동으로 그리지 않고 학생이 막대 끝을 끌어 높이를 맞추거나 꺾은선 점을 찍는다. [확인]을 누르면 맞는 칸은 초록, 틀린 칸은 위치를 알려 줌.
- **평균**(막대·꺾은선): 평균선 켜기. 막대에서 [고르게 하기]를 누르면 높은 막대의 칸이 낮은 막대로 옮겨 가 모두 평균 높이가 되는 애니메이션([6수04-01]).
- **내보내기**: PNG 내려받기(SVG → canvas), A4 인쇄, `#share=` 공유 링크(표 자료·종류·설정. 개인정보 없음).
- **예시 자료**: 좋아하는 계절(막대·원), 우리 반 생일 달(막대), 하루 기온 변화(꺾은선), 일주일 줄넘기 횟수(평균), 학교 텃밭 넓이(띠).

### 2-3. 미션 (SimKit, 3묶음)
| 묶음 | 미션 |
|---|---|
| 1~2학년 | m1 분류해서 표 만들기(그림 카드 끌어 넣기) · m2 ○그래프 그리기 |
| 3~4학년 | m3 그림그래프 읽기(큰 그림·작은 그림) · m4 눈금 한 칸이 5인 막대그래프 읽기 · m5 표 보고 막대 직접 그리기 · m6 물결선이 있는 꺾은선 읽기·중간값 짐작 |
| 5~6학년 | m7 띠그래프 백분율 구하기 · m8 원그래프 읽기 · m9 평균 구하기(고르게 하기) · m10 상황에 알맞은 그래프 고르기(변화 → 꺾은선, 부분과 전체 → 띠·원, 크기 비교 → 막대) |

- 숫자 자료는 매번 무작위로 만들되 답이 깔끔하게 나오도록(백분율 합 100, 평균이 정수 또는 소수 첫째 자리).
- 별: 첫 시도 정답 ★3, 두 번째 ★2, 그 외 ★1. 자동 이동 없음.

### 2-4. 태블릿 조작
- 학생 태블릿 손가락 조작이 기본. 셸은 기존 시뮬레이션 관행대로 `immersive`.
- 값 입력: 칸을 누르면 앱 안 숫자 입력판(0~9, ←, ±1 버튼)이 열린다. 화면 키보드는 항목 이름·제목을 고칠 때만.
- 직접 그리기: 막대 전체 폭을 잡기 영역으로(끝을 정확히 집지 않아도 됨), 끄는 동안 막대 위에 지금 값 말풍선. 그래프 영역 `touch-action: none`.
- 조사하기 버튼은 화면 높이에 맞춰 크게(최소 64px), 연속으로 빠르게 눌러도 놓치지 않게 `pointerdown`에서 센다.
- 가로 화면: 표 왼쪽 · 그래프 오른쪽. 세로 화면: 그래프 위 · 표 아래(접기 가능).

## 3. 공용 그래프 모듈 `public/common/vgraph.js`

`sun-shadow`의 측정 기록 그래프에서 다시 쓰므로 공용으로 둔다. 범위는 **막대·꺾은선만**(나머지 종류는 앱 안에 둠).

```js
VGraph.bar(svgEl, { title, unit, items:[{label, value}], step, horizontal, showValues, avg })
VGraph.line(svgEl, { title, unit, items, step, wave:{from}, showValues, avg })
VGraph.niceStep(max, maxTicks)   // 1·2·5·10… 눈금 한 칸 자동
```
- 출력은 SVG 요소만(이벤트 없음). 색은 CSS 토큰(`--vg-bar`, `--vg-line`, `--vg-grid`)으로 앱이 바꾼다.
- 글자는 `textContent`로만 넣는다(공유 링크로 들어온 항목 이름 보호).
- 화면 낭독기용 `<title>`·`<desc>`와 표 요약(`aria-describedby`)을 함께 만든다.

## 4. 계산 규칙

- **눈금 자동**: 최댓값을 5~10칸에 담는 1·2·5 × 10ⁿ 중 가장 작은 값.
- **백분율**: 기본은 일의 자리까지 반올림. 합이 100이 아니면 표 아래에 "반올림해서 합계가 99%예요"라고 알린다. [합계 100으로 맞추기]를 켜면 버린 부분이 가장 큰 항목부터 1%씩 더한다(최대 나머지 방법). 교과서 풀이와 다를 수 있어 기본은 끔.
- **띠그래프 칸**: 100칸 기준으로 그린다(1칸 = 1%).
- **평균**: 소수 둘째 자리에서 반올림해 표시, 계산은 원래 값으로.

## 5. 저장·공유

- `SimKit.store('graph-maker:v1', { defaults: { tables: [], current: null, progress: {} } })`: 만든 표를 최대 20개 보관.
- `SimKit.share.bind(() => ({ v:1, table, type, opts }))`. 받으면 항목 수(12)·이름 길이(20자)·값 범위·종류 목록으로 검사.

## 6. 하지 않는 것

- 줄기와 잎 그림, 히스토그램, 산점도(중학교 범위)
- 두 자료 묶음을 한 그래프에(겹친 막대, 꺾은선 두 개) — 2차 후보
- 설문 링크로 학생 기기에서 응답 모으기(서버 필요. 에듀링크 설문이 이미 있음)

## 8. 확인 목록

- [ ] 눈금 자동이 교과서와 비슷한 칸 수가 된다(최댓값 7 → 한 칸 1, 23 → 5, 180 → 20)

## 9. 구현 메모 (2026-10-06)

계획과 달라진 점:
- ○그래프는 세로 방향만(가로 방향 설정은 넣지 않음). 20 이하의 자연수 자료에 알맞다고 안내.
- 만든 표는 **지금 표 하나만** 자동 저장(여러 표 보관 목록은 넣지 않음). 다른 기기·친구에게는 공유 링크나 PNG로.
- 미션은 묶음 3개 대신 번호 10개를 한 줄로 두고 제목 옆에 학년(1~2/3~4/5~6)을 표시.
- 띠·원그래프 미션에서 가린 백분율은 화면 낭독기 설명에서도 "?"로 가림.
- 조사하기 단추는 손가락·마우스는 누르는 순간(pointerdown), 키보드·화면 낭독기는 click으로 센다(두 번 세지 않음).

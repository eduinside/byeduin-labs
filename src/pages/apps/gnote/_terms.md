# G노트 이용 안내 · 약관

- 시행일: 2026년 10월 11일 (2차 — G노트 0.9.1 사용 통계. 0.8.3 첫 판 · 0.8.4 외부 달력 · 0.9.0 업데이트 서버)
- 이 안내가 바뀌면 시행일과 판을 바꾸고 업데이트 내역에 적어요.

## 1. 이 앱은

G노트는 대구의 교사 한 사람이 만들어 무료로 나누는 **개인 업무 도구**예요. 상업 서비스가 아니고, 회원 가입·로그인이 없어요. 공문·법령·지침·내 문서를 노트북에 모으고, 근거를 찾아 답하고, 초안을 만드는 일을 돕습니다.

- 만든 사람·문의: eduin.info (byeduin)
- 이 앱을 쓰면 아래 안내에 동의한 것으로 봐요. 동의하지 않으면 앱을 쓰지 말고 지워 주세요.

## 2. 보증과 책임

- G노트는 **있는 그대로** 제공해요. 오류가 없다거나 특정 업무에 꼭 맞는다고 보증하지 않아요.
- 앱을 쓰다 생긴 데이터 손실, 업무 판단 결과, 외부 서비스(AI 서버·corepin 등) 이용에서 생긴 문제에 대해 만든 사람은 법이 허용하는 범위에서 책임을 지지 않아요.
- 자료는 이 PC에만 있으니 **백업은 직접** 해 주세요(설정 › 데이터 · 백업).

## 3. 법령 정보와 AI 답의 성격

- G노트의 답은 **법률 자문이 아니라 조문 정리**예요. 법적 판단은 반드시 국가법령정보센터 원문과 담당 부서·전문가 확인으로 하세요.
- AI 답의 근거 번호 [n]을 눌러 원문을 직접 확인하세요. AI는 틀린 말을 그럴듯하게 할 수 있어요.
- AI가 만든 회신·기안·양식 초안은 **사람이 고쳐 쓰라고 만든 초안**이에요. 그대로 보내지 마세요.

## 4. 개인정보

- G노트는 개인정보를 모으거나 저장하는 **서버가 없어요.** 노트북·공문·메모·AI 대화 기록·설정은 모두 이 PC의 데이터 폴더에만 있어요.
- 키(AI 서버·법제처 OC·corepin)와 외부 달력 주소는 Windows 사용자 계정으로 암호화(DPAPI)해 이 PC에 둬요. 다른 PC로 옮기면 다시 넣어야 해요.
- 내 정보(기관·이름·연락처)는 회신·기안·양식 초안을 만들 때만 AI 서버에 보내요.
- 오류 보고는 자동으로 보내지 않아요. **사용 통계**는 설치판에서 익명 번호 하나만 보내요(아래 6-1, 끌 수 있음).

## 5. 이 PC 밖으로 나가는 것

| 어디로 | 무엇을 | 언제 |
| --- | --- | --- |
| 법제처 국가법령정보센터 | 검색어, 법제처 OC(사용자 ID) | 법령·판례 찾기·열기, 개정 소식 확인 |
| 고른 AI 서버 (Google Gemini · OpenAI · Anthropic Claude · OpenRouter) | 질문과 근거로 고른 자료(아래 6의 공개 구분 규칙대로), 내 정보(초안만) | 근거 찾아 답하기·요약·초안·인포그래픽 등을 쓸 때 |

| OCR 모델 내려받기 (huggingface.co) | 내려받기 요청 | 글자 인식(OCR)을 처음 쓸 때 (전체판에서 OCR 을 켠 경우) |

- **로컬 AI**(Ollama, 또는 이 PC·학교 안 서버 주소의 직접 입력 서버)와 **문서 도구**(kordoc)는 이 PC(또는 학교 안) 안에서 돌아서, 자료가 인터넷 회사 서버로 나가지 않아요.
- 각 외부 서비스에 보낸 자료는 그 서비스의 이용약관·개인정보 정책을 따라요.

## 6. 공문을 AI에 보낼 때 — 공개 구분 규칙

공문 끝(전화 줄 옆)의 **공개 구분**에 따라, 외부 AI 서버와 corepin 으로 보내는 범위를 앱이 정해요.

| 공문 공개 구분 | 외부 AI 서버 · corepin | 로컬 AI · 문서 도구 |
| --- | --- | --- |
| 공개 | 본문·첨부 모두 | 모두 |
| 부분공개 | **본문만** (첨부는 보내지 않음) | 모두 |
| 비공개 | **아무것도 보내지 않음** (제목·요약·할 일 포함) | 모두 |
| 공개 구분을 못 읽음 | 부분공개처럼 본문만 | 모두 |
| 공문이 아닌 문서·메모 | 제한 없음 | 모두 |

- 공개 구분이 잘못 읽혔으면 문서 보기의 **‘AI’ 칩**을 눌러 바꿀 수 있어요. 보내는 범위가 넓어지게 바꿀 때는 한 번 더 확인해요.
- **공개 공문이라도** 학생·학부모·교직원 개인정보가 들어 있으면 AI 에 보내기 전에 지우는 것은 사용자 책임이에요.
- 메모·노트에 사용자가 직접 옮겨 적은 글은 사용자 글로 보아 이 규칙을 적용하지 않아요.
- 교육부·교육(지원)청의 **생성형 AI 활용 지침**을 따라 주세요.
- **무료 등급 AI**(구글 무료 키, OpenRouter 무료 모델 등)는 보낸 내용을 서비스 개선·학습에 쓸 수 있어요. 민감한 자료는 유료 등급이나 로컬 AI 를 쓰세요.
- AI 서버 요금은 각자의 키로 내요. 앱에 보이는 금액은 대략값이에요.

## 6-1. 사용 통계 (설치판, 0.9.1~)

몇 명이 G노트를 쓰는지 알려고, 설치판이 새 판을 확인할 때 아래만 함께 보내요.

| 무엇 | 설명 |
| --- | --- |
| 익명 설치 번호 | 설치할 때 만든 **무작위 값**이에요. 이름·학교·PC 이름·Windows 계정·하드웨어 정보와 아무 관계가 없어요. 지우고 다시 설치하면 새 번호가 돼요 |
| 판 | 쓰고 있는 G노트 판 (예: 0.9.1) |

- 서버(eduin.info)에는 번호를 **바꾼 값**(해시)과 날짜·판만 하루 한 줄 남겨요. **번호 원문·IP·브라우저 정보는 저장하지 않아요.** 그래서 이 값으로 누구인지 알 수 없어요.
- 90일이 지나면 날짜별 사용자 수(합계)만 남기고 지워요.
- 문서·공문·메모·키·내 정보 같은 자료는 **보내지 않아요.**
- **끄는 법**: 설정 › 데이터 › 업데이트 › ‘사용 통계 보내기’를 끄면 번호를 보내지 않아요(업데이트 확인은 그대로). ‘자동 업데이트’를 끄면 확인 자체를 하지 않아요.
- 설치 파일 내려받기 횟수도 날짜별로 세요(누가 받았는지는 남기지 않아요).

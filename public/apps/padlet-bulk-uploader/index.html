📌 패들렛 일괄 업로더

텍스트를 붙여넣으면 내 패들렛 보드에 게시물을 한 번에 업로드합니다.

⚠️ 이 기능은 패들렛 유료 구독 계정에서만 동작합니다. 무료 계정과 그룹(조직) 계정은 지원되지 않습니다. 반드시 업로드하려는 보드의 관리자 권한이 있는 개인 계정으로 진행하세요.
  1. 패들렛 대시보드에 로그인 → 업로드할 보드를 엽니다.
  2. 보드 화면 우측 상단 ···(더보기) 메뉴 → Developer를 클릭합니다.
  3. 열린 패널에서 Generate(또는 Copy) 버튼으로 API 키를 발급/복사합니다. 계정당 키는 1개이며, 이 계정이 관리자인 모든 보드에 재사용할 수 있습니다.
  4. 같은 패널이나 보드 URL 끝부분에서 Board ID(16자리 영숫자)를 복사합니다. 이 앱에는 보드 URL을 그대로 붙여넣어도 자동으로 인식합니다.
  5. API 키를 계정 설정에서 바로 발급하려면 Settings → Developer 페이지를 이용하세요.
연결 설정
🔒 API 키는 브라우저에서 이 서버의 프록시 함수로만 전달되며, 서버에 저장되거나 로그에 기록되지 않습니다.
